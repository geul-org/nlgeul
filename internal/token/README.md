# token

`kopas token`의 읽기. 토큰(음절) 스트림을 조각으로 가르고 어절로 끊어 올리는 데까지만 한다(실험, 설계는 작업 문서 `stream-graph-algorithm.md`). 문장성분은 정하지 않는다. `Lines(문장, trace)`가 줄을 돌려준다.

## 색인과 그래프

- 표지 풀이 하나에 toulmin 그래프 하나다(`markerGraph`). 그래프는 문법 표의 한 줄(`parse.ParticleMarkers`, `parse.ClosingMarkers`, 선어말 칸 `slotRows`)과 그 표지로 끝나는 닫힌 집합 낱말 목록에서 찍어낸다. 이름은 `주격:이`, `보조사:은`, `꾸밈:은`, `선어말:었`, `맺음:지만` 꼴이다.
- 그래프의 주장은 "이 자리의 이 토큰 열은 이 표지다"(`rule.PieceRead`)이고, 구조를 보는 예외가 그것을 꺾는다: 앞에 줄기가 없다(`PieceNoStem`), 앞 토큰의 끝이 안 맞는다(`PieceAfter`), 조사 사슬의 순서(`ChainOrder`), 선어말 칸의 순서(`SlotOrder`), 받침만 붙은 꼴을 읽는 음절이 아니다(`PieceBase`), 통째로 닫힌 집합의 낱말이다(`WordListed`). 규칙 함수는 모두 `pkg/rule`의 것이고 기준만 다르다.
- 닫힌 집합 낱말(의존명사, 보조 용언, 관형사, 접속 부사)은 열쇠다. 주장 하나뿐인 그래프를 갖는다. 표에 없는 토큰 열은 `새 낱말` 그래프가 판정한다(주장에 "열쇠 표에 없다"는 반박이 힘 0.5로 붙어 verdict 1/3).
- 색인(`index`)은 표지 꼴의 마지막 토큰에서 그 표지들로 간다. 합쳐진 토큰은 토큰 그대로와 받침(ㄴ, ㄹ, ㅁ, ㅂ, ㅆ)·모음(어/아)의 열쇠 양쪽으로 찾는다(`keysAt`).

## 스트림 읽기

- 단위는 띄어쓰기 사이다(앞뒤 문장 부호는 뗀다). 단위 밖은 보지 않는다.
- 토큰 자리마다 거기서 끝나는 표지 열을 색인에서 찾아 그래프를 돌린다(`tailsAt`: 조사 사슬 `chains`, 선어말 칸 `slots`, 맺음 `closings`). 기각된 것은 버린다.
- 읽기(`path`)는 어절의 연쇄다. 어절은 줄기(새 낱말 또는 열쇠)와 그 뒤 표지들이다. 표지 없는 어절은 닫힌 집합 낱말이거나 단위의 끝에서만 선다.
- 성립은 조각 verdict의 최솟값, 선호는 조각마다 log10(관측 횟수 ÷ 표의 총 횟수)의 합이다. 횟수가 없는 표지와 줄기는 음절마다 log10(1/11172)로 친다. 자리마다 가장 나은 읽기 16개를 남기고(`beam`), 끝에 닿은 것 가운데 7개까지 올린다(`branches`).
- 남은 읽기가 모두 합의한 자리에서 끊는다(`agreed`). 끊긴 구간마다 읽기가 하나면 한 줄, 여럿이면 경합 묶음이다(`bundles`, `render`).

`--trace`는 걸린 토큰 열, 그래프, verdict, 기각 이유를 찍고, `--cuts`는 측정용으로 읽기마다 어절 끝 자리만 찍는다.

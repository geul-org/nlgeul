# token

`nlgeul token`의 읽기. 토큰(음절) 스트림을 조각으로 가르고 어절로 끊어 올리는 데까지만 한다(실험, 설계는 작업 문서 `token-stream-algorithm.md`). 문장성분은 정하지 않는다. `Reader.Bundles(문장)`이 결과를 구조로 돌려주고, `Reader.Lines(문장, trace)`가 같은 구조를 글줄로 찍어 돌려준다.

## 올려 보내는 구조

위층(어절 층)은 글줄을 쪼개지 않고 이 구조를 받는다. `Lines`는 이 구조를 찍을 뿐이다(`render`, 타입마다 `String`). 찍는 길은 하나다.

```go
r, _ := token.New(token.Options{Words: "words.tsv"})
for _, b := range r.Bundles("작은 곰이 물을 마신다.") {
	best := b.Branches[0]
	last := best.Words[len(best.Words)-1].Parts
	_ = last[len(last)-1].Names // 끝 조각의 풀이: [{꾸밈 은}] …
}
```

| 타입 | 칸 | 뜻 |
|---|---|---|
| `Bundle` | `Unit` | 문장의 몇째 단위에 든 묶음인가(0부터) |
| | `Text` | 그 구간의 글자 |
| | `Branches` | 갈래들, 나은 것부터. 하나면 확정, 둘 이상이면 경합(`Contest()`) |
| `Branch` | `Words` | 어절들. 단위 안에 경계가 선 갈래는 둘 이상이다 |
| | `Verdict`, `Pref` | 성립(조각 verdict의 최솟값), 선호 |
| `Eojeol` | `Parts` | 조각들. 줄기가 먼저, 그 뒤가 표지 |
| | `End` | 단위 안에서 이 어절이 끝나는 자리(토큰 수) |
| | `Attach` | 줄기 없이 표지만 있는 어절인가. 띄어 쓴 표지 단위(`로`, `에서`, `인데`)를 앞 단위에 붙는 표지로 읽은 것이고, `+로[부사격:로]`처럼 `+`로 시작하게 찍는다 |
| `Part` | `Text` | 글자. 줄기는 찾는 꼴(되돌린 줄기, 불규칙의 본디 줄기, 줄임이 가리키는 낱말) |
| | `Hidden` | 글자에 안 보여 풀어 쓴 부분(`(ㄴ)다`의 `ㄴ`, 빠진 `(이)`의 `이`) |
| | `Names` | 풀이들. `주격:가|보격:가`는 둘이다 |
| | `Stem` | 줄기인가(아니면 표지: 조사, 선어말, 맺음, 단위, 기호) |
| | `Unseen` | 글자에 흔적이 전혀 없는 조각인가 |
| `Name` | `Kind`, `Form` | 풀이의 갈래(`주격`, `꾸밈`, `열쇠`, `맺음`, `수`, `경로` …)와 꼴(`가`, `은`, `체언` …). 갈래만으로 다인 것은 꼴이 비어 있다 |

- 한 단위의 묶음은 이 차례로 나온다: 읽기들이 모두 합의한 구간마다 하나, 단위를 닫는 점이 있으면 하나(`.[마침표:.]`는 줄기 없는 조각 하나짜리 어절이다).
- 표가 모르는 줄기(새 낱말)는 `Names`가 비어 있다. 낱말 표가 준 갈래는 풀이 하나씩이다(`열쇠:체언|부사` → `{열쇠 체언}`, `{열쇠 부사}`).
- 수, 주소·경로·옵션, 짝이 맞는 여닫는 기호와 코드는 줄기 조각이고 이름이 그것을 말한다(`{수}`, `{경로}`, `{여는 묶음표}`, `{코드}`). 읽을 것이 없는 단위(기호뿐)는 글자 그대로 조각 하나짜리 묶음이다.
- 추적(`--trace`)은 구조에 없다. `Lines`가 단위마다 구조 앞에 찍는다.

## 색인과 그래프

- 표지 풀이 하나에 toulmin 그래프 하나다(`markerGraph`). 그래프는 문법 표의 한 줄(`parse.ParticleMarkers`, `parse.ClosingMarkers`, 선어말 칸 `slotRows`)과 그 표지로 끝나는 닫힌 집합 낱말 목록에서 찍어낸다. 이름은 `주격:이`, `보조사:은`, `꾸밈:은`, `선어말:었`, `맺음:지만` 꼴이다.
- 그래프의 주장은 "이 자리의 이 토큰 열은 이 표지다"(`rule.PieceRead`)이고, 구조를 보는 예외가 그것을 꺾는다: 앞에 줄기가 없다(`PieceIs`, 기준 `PieceStem`에 `Not`), 앞 토큰의 끝이 안 맞는다(`PieceAfter`), 조사 사슬에 맞지 않는다(`ChainLinks`), 선어말 칸의 순서(`SlotOrder`), 받침만 붙은 꼴을 읽는 음절이 아니다(`Listed`에 `Not`, 낱말 표가 없을 때만), 통째로 닫힌 집합의 낱말이다(`Listed`). 어/아/여로 시작하는 조각이 앞 모음과 어긋나면 반박 `PieceClash`가 낮춘다(`먹아`는 지우지 않고 뒤로 보낸다). 규칙 함수는 모두 `pkg/rule`의 것이고 기준만 다르다: 참/거짓 사실 하나를 보는 판정은 `PieceIs`, 목록에 있는지 보는 판정은 `Listed` 하나가 기준으로 갈라 맡고, 반대 방향은 기준 `Not`으로 준다. 예외는 왜 꺾는지를 그 노드에 싣고(`except`), `--trace`는 그 노드의 이유를 찍는다.
- 받침으로 끝난 이름 뒤의 `이`(`영숙+이+가`)는 이 층만 읽는 표지 `접미:이`다(`innerSuffixes`). 받침 뒤에만 붙고 조사 사슬의 맨 앞자리이며, 뒤에 조사가 이어질 때만 선다(예외 `PieceIs`, 기준 `PieceLast`). 그래서 `고양이가`는 `고양이+가`와 `고양+이+가`가 함께 올라간다. `nlgeul parse`의 조사 표에는 없다.
- 서술격 이다(`morphemes.md` 2절)는 줄기 `이`의 그래프 `서술격:이`가 읽는다(`addCopula`, `copulas`). 주장은 "이 `이`는 체언 뒤 이다의 줄기다"이고, 예외는 앞에 줄기가 없다와 이 바로 뒤에 선 맺음이 이다에 붙지 않는 것이다(`Listed`, 맺음 표의 표시). 이 뒤에 선어말이 먼저 서면 그 선어말을 보므로 그런 맺음도 선어말 뒤에서는 선다(`firstName`: `학생+이+었+습니다`, `학생+이+었+는데`). 맺음 아래에 합쳐진 꼴은 풀어 찍는다(`학생+이+(ㅂ)니다`, `학생+이+(ㄴ)`, `문제+이+(었)+다`). 모음 뒤에서 이가 빠진 꼴은 그래프 `서술격:이(빠짐)`이 2절에 적힌 맺음(다, 고, 며, 면, 지만, ㄴ, ㅂ니다) 앞에서만 읽고 `학교+(이)+다`로 찍는다. "모음 뒤"와 "이가 빠지는 맺음의 목록에 있다"는 둘 다 그 그래프의 예외다(`PieceAfter`, `Listed`에 `Not`. 목록은 `droppable`이고 낱말 표가 있으면 `droppableKnown`을 더해 그래프를 짠다). 이와 맺음 사이에 선어말이 끼면 빠진 이로 읽지 않는다. 낱말 표가 있으면 네·냐·니·라·거든·구나·군·야·니까·죠·냐고·더라도·거나·든지·든가와 인용 꼴 라는·라며·라면서·라니 앞에서도 읽되, 앞말이 표의 체언이나 의존명사일 때만이다(`droppableKnown`: `거+(이)+네`, `뭐+(이)+냐`, `사과+(이)+라는`). 흔적이 없는 조각이라 3겹에서 값을 치른다. 이다에만 붙는 맺음(에요, 야, 라서 들)은 `서술격:이` 뒤와 줄기 `아니` 뒤에만 서고, 이다를 품은 맺음(예요)은 체언 뒤에 바로 선다. 낱말 표가 있으면 서술격 꼬리는 체언 줄기와 맞는다(`kindTails`). 횟수는 표의 452만이고, 다른 표지의 선호가 달라지지 않도록 표지 횟수의 합에는 넣지 않는다. 이가 빠진 꼴을 읽는 맺음은 다, 고, 며, 면, 지만, ㄴ, ㅂ니다, 라서, 라면, 지, ㄴ지, ㄴ데, ㄴ가, ㄹ까이고 `잖`(지+않) 앞에서도 읽는다(`학교+(이)+라서`, `학교+(이)+지+(않)+아`). 꾸밈 맺음 ㄴ 앞에서는 반박 `Listed`가 낮춘다(관형형 앞에서는 이가 대체로 빠지지 않는다). 낱말 표가 있으면 이름 꼴 맺음 기 앞에서도 읽되, 기 바로 뒤에 조사가 이어질 때만이다(`문제+(이)+기+도`, `문제+(이)+기+는`. `문제기`만으로는 읽지 않는다): 빠진 이의 그래프에 예외 "뒤가 이름 꼴 맺음이다"(`Listed`, `dropNaming`)가 있고, 그 예외를 "바로 뒤에 조사가 붙는다"(`PieceRight`)가 다시 꺾는다. 앞말은 표의 체언이어야 하고, 꾸밈 맺음 앞과 같은 반박이 낮춘다(`dropAdn`). 앞 글자가 한글 음절이 아니면(영숫자 열, 수, 코드, 파일명) 받침이 있는지 글자로 알 수 없다. 그 뒤의 빠진 이는 이다에만 붙는 맺음 `야` 앞에서만 읽는다(`abc+(이)+야`, `droppableRun`): 예외 "앞 글자가 한글 음절이 아니다"(`PieceAfter`)를 "뒤의 맺음이 그 목록에 있다"(`Listed`)가 다시 꺾는다. 이 자리에서는 앞말이 표의 체언인지 묻지 않고, 낱말 표가 있을 때만 읽는다(`야`가 `droppableKnown`의 맺음이다). 다른 맺음(다, 고, 면, 네) 앞의 영숫자 열은 전처럼 그 맺음의 줄기로만 읽는다(`abc+다`).
- 두 조각이 합쳐진 글자(`addFused`, 표는 `fused_table.go`). `셨`·`셔`·`십`은 줄기의 끝 음절 `시`에 조각이 합쳐진 것으로 읽는 자리마다 높임 선어말 `시`로도 읽는다(`honors`: `가+시+(었)+다`, `가+시+(어)서`, `가+시+(ㅂ)니다`). 높임 `시`는 모음 뒤에 서고, 받침(ㄹ 아닌) 뒤에서는 이음 `으`가 앞에 선다(`읽+으+시+(었)+다`, 그래프 `이음:으`). 이음 `으`는 조각 하나이고 `시` 앞과 맺음 니·니까·나·냐 앞, 줄기 뒤와 선어말 었·겠 뒤에 선다(`linked`: `읽+으+시+고`, `먹+었+으+니`; 예외 `Listed`에 `Not`). 으를 받는 다른 맺음은 표에 으가 든 꼴이 따로 있다(으면, 은, 을). 으가 든 꼴(은, 을, 음, 읍시다, 으면 …)은 ㄹ 아닌 받침 뒤에만 붙는다(`euAfter`): ㄹ 받침 줄기는 ㄴ·ㄹ·ㅁ과 으 없는 꼴을 받는다(`물 것`, `살면`). 문법 표는 "받침 뒤"로 적고 있어 이 층의 색인에서 좁힌다. 다만 낱말 표가 있으면 ㄹ을 빼지 않고 꾸밈 맺음 `은`·`을`을 붙인 꼴도 표의 용언 줄기 뒤에서 읽는다(`looseClosings`: `줄+은[꾸밈:은]`, `살+을[꾸밈:을]`. 한글 맞춤법 제18항에 어긋난 꼴이고 바른 꼴은 `준`, `살`). 따로 둔 색인 항목이고 ㄹ 받침 뒤에만 붙으며(`AfterLiquid`), 앞말이 표의 용언 줄기여야 하고(`앞말:용언`), 반박 "으가 든 꼴은 ㄹ 아닌 받침 뒤에 붙는다"(`PieceAfter`, 힘은 `forceClash`)가 낮춘다. 표의 꼴대로 읽은 풀이(`줄[의존명사]+은[보조사:은]`, `주+(ㄴ)`)는 그대로 선다. `으면`, `음` 같은 다른 으 꼴은 넓히지 않았다. 줄기 풀이(`마시+(었)+다`)는 그대로 나란히 서고, 낱말 표의 갈래 맞춤이 둘을 가른다. `잖`은 맺음 `지`와 `않`으로 풀고 뒤의 맺음은 `않`에 붙는다(`negated`: `하+(였)+지+(않)+아`). 맺음 `어야`(합쳐진 꼴 포함) 바로 뒤의 `겠`은 `어야 하겠`에서 `하`가 준 것으로 풀어 보조 용언 `하`를 괄호에 적고, `겠`과 뒤의 맺음은 `하`에 붙는다(`obliged`, `mustNames`: `가+(아)야+(하)+겠+다`, `먹+어야+(하)+겠+네`). 같은 단위 안에서 `어야` 뒤에 바로 붙은 `겠`만이다(띄어 쓴 `겠다`는 읽지 않는다). 표의 맺음 `죠`, `십시오`, `세요`, `더라`는 조각으로 풀어 찍는다(`splits`: `그렇+지+(요)`, `가+시+(ㅂ)시오`, `가+시+(어)+요`, `하+더+라`). 풀어 찍은 맺음은 조각을 하나씩 읽은 풀이와 같은 갈래라 한 번만 올라간다. 찍힌 이름 가운데 `맺음:ㅂ시오`와 `부정:않`은 그래프가 따로 없는 조각 이름이다. 앞말이 정해진 꼴(`contracts`: 이게, 이건, 이걸, 뭘, 무얼, 누가, 누굴, 누군, 여긴, 여길, 우린, 우릴, 그땐, 땐 들과, 대명사 꼴 내·네·제 뒤의 격조사 `게`인 내게·네게·제게(`내+게[부사격:에게]`), 어디·여기·거기·저기 바로 뒤의 `다`·`다가`인 어디다·여기다가 들(`어디+다[부사격:에다]`, `여기+다가[부사격:에다가]`). `게`와 `다`·`다가`는 글자 그대로 적고 표의 `에게`·`에다`·`에다가` 줄의 이름과 횟수로 읽는다. 낱말 표가 있으면 한 음절 대명사에 받침으로 붙은 조사 난·넌·전·날·널·절·걘·얜·쟨도: `shortPronouns`)은 낱말과 그 아래의 조사로 풀고(`fixed`: `이것+(이)[주격:이]`), 뒤에 조사가 더 붙는지는 그 조사의 갈래로 사슬 표가 정한다(`이것+(은)+요`). 닫힌 집합이라 표에 적힌 꼴만 읽고, 낱말 표가 그 낱말을 모르면 꼴의 이름(`줄임:이게`)으로 안다. 일반 낱말 뒤의 받침 조사(`친군`)는 읽지 않는다(갈래 수를 줄이려는 선택이다). 꾸밈 맺음으로 끝난 어절 바로 뒤의 `게`·`건`·`걸`은 의존명사 `거`와 그 아래의 조사다(`하+는 거+(이)`, `하+(ㄴ) 거+(는)`; 예외 `PieceIs`, 기준 `PieceAdn`에 `Not`. 꼬리를 찾는 자리에서는 "어느 읽기든 꾸밈꼴이 여기서 끝난다"로 묻고, 읽기에 이을 때 그 읽기의 마지막 어절로 같은 그래프에 다시 묻는다: `again`). 겹치는 맺음(ㄹ게, ㄹ걸)과 낱말은 지우지 않고 나란히 선다. 꾸밈 맺음으로 끝난 어절 바로 뒤의 `테`는 의존명사 `터`에 서술격 이다의 줄기가 합쳐진 것으로도 읽는다(`nounCopulas`, `addNouns`, `nounCopula`: `하+(ㄹ) 터+(이)+니까`, `가+(ㄹ) 터+(이)+(ㄴ)데`. `터이니`, `터인데`가 줄어든 꼴이다). 뒤에 이다가 받는 맺음이 바로 붙거나(`테니`, `테고`, `테야`) 받침으로 합쳐진다(`텐데`, `텐가`). 그래프 `줄임:테`의 예외는 셋이다: 앞 어절이 꾸밈 맺음으로 끝나지 않는다(`PieceIs`, 기준 `PieceAdn`에 `Not`. 게·건·걸과 같이 읽기마다 다시 묻는다), 뒤의 맺음이 이다에 붙지 않는다(`Listed`), 뒤의 조각이 이 글자의 모음에 합쳐진 어/아나 ㅆ이다(`Listed`, 목록은 `fusedNames`: `터이+어`는 `테`가 아니다). 이는 글자에 흔적이 있어 `(이)[서술격:이]`로 찍고 흔적 없는 조각의 값을 치르지 않는다. 줄기 `터`는 낱말 표가 있으면 표의 체언으로, 없으면 꼴의 이름(`줄임:테`)으로 선다. 낱말 `테`로 읽은 풀이와 같은 글자의 낱말(`테고`, `테지`)은 그대로 나란히 선다.
- 낱말 속에도 흔한 합쳐진 글자(`addWide`, 표는 `wide_table.go`)는 낱말 표가 있을 때만 읽고, 다른 풀이를 지우지 않고 나란히 세운다. 앞말이 낱말 표의 용언 줄기(줄어든 조사는 체언)여야 한다: 꼬리가 줄기를 만나는 자리에서 그래프 `앞말:용언`·`앞말:체언`이 판정한다(`gated`, 예외 `StemKind`). 높임 `시`가 든 `신`·`실`·`심`·`세`는 `셨`과 같은 자리(줄기 끝 `시`+조각으로 읽는 곳)에서 `시`를 한 칸 끼워 읽는다(`가+시+(ㄴ)다`, `가+시+(ㄹ)까`, `가+시+(ㅁ)+을`, `가+시+(어)+요`, 받침 뒤 `읽+으+시+…`). 글자의 그래프(`합침:신` 들)의 예외: 받침만 떼어 낸 꼴 바로 뒤에 조사가 붙는다(`PieceRight`, `사신이`. `심`은 예외), 떼어 낸 받침이 뒤 토큰과 표의 맺음을 이루지도 단위가 끝나지도 않는다(`PieceRight`, `사신고`). `세`는 `요` 앞에서만 읽는다. 인용이 줄어든 맺음(`대`, `ㄴ대`, `는대`, `래`, `으래`, `재`, `단`, `ㄴ단`, `는단`, `란`, `으란`, `잔`)과 `진`·`긴`·`길`은 한 조각이고 이름에 본디 꼴을 적는다(`간+대[맺음:ㄴ대(ㄴ다고 해)]`, `하+진[맺음:진(지는)]`). 바로 뒤에 조사가 붙으면 기각하고(`요`는 받는다), `대`·`단`은 형용사 줄기 뒤에 바로, 동사는 `ㄴ대`·`는대`로, `래`·`재`·`란`·`잔`은 동사 뒤에 선다(`kindTails`). 줄어든 조사 `선`(에서는)·`론`(로는)은 `엔`·`에선`처럼 한 조각이고 사슬을 닫는다(`여기+선[부사격:선(에서는)]`). 인용에 과거가 합쳐진 `댔`·`랬`·`쟀`(다고/라고/자고 했)은 선어말 자리의 한 조각이고(`shortSlots`: `가+(ㄴ)댔+어`, `하+랬+는데`), `냬`(냐고 해)는 맺음 한 조각이다. 사전에 없는 꼴이고 `해` → `했`과 같은 이치로 읽는다.
- 숫자(`addNumbers`, 표는 `number_table.go`). 숫자만으로 된 열은 수다(`수:숫자열`, `3[수]`). 글자가 섞인 열(`L2`, `v1`)은 영숫자 열로 남는다. 두 숫자 열 사이의 기호 하나(`,` `~` `-` `:` `/` `.`)는 풀이마다 그래프가 판정하고(예외 `PartsShape`: 같은 기호로 이어진 마디들의 수, 자리 수, 값의 범위, 첫 마디의 머리), 선 풀이가 있으면 열을 한 수로 잇고 그 이름을 단다. 자릿수 `,`는 첫 마디 1~3자리와 그 뒤 3자리씩(`1,000[수]`), 범위 `~`·`-`는 두 마디, 시각 `:`은 1~2자리(0~24):2자리(0~59)에 초까지, 비율 `:`은 두 마디, 날짜 `-`·`.`은 4자리-월(1~12)-일(1~31), 날짜 `/`는 월/일, 나눔 `/`는 두 마디, 전화 `-`는 0으로 시작하는 2~4자리-3~4자리-4자리, IP `.`은 0~255 네 마디다. 겹치는 풀이는 함께 선다(`10:30[시각|비율]`, `11/10[날짜|나눔]`, `2026.11.10[버전|날짜]`, `1.2.3.4[버전|IP]`). 수의 맨 앞에 선 `-` `+` `$` `₩`는 왼쪽에 글자가 붙지 않았을 때 수에 든다(`-3[부호|수]`, `$40[돈|수]`; 단위 가장자리의 이 기호와 수 뒤의 `%`·`℃`는 떼지 않는다, `trimUnit`). 수 바로 뒤에는 `여`(어림), 단위 표의 낱말, `째`(차례)가 이 차례로 조각으로 선다(`units`, 예외 `PieceIs`, 기준 `PieceNum`에 `Not`): `3[수]+개[단위:개]+를`, `3+번+째`, `10+여`, `20+ms[단위:ms]`. 단위 표는 닫힌 표이고 수 뒤에서만 읽는다. 단위 뒤, `째`가 서는 자리에 접미 `짜리`·`가량`·`당`이 선다(`백+원+짜리`, `3+명+당`). 긴 단위와 그것의 앞쪽 짧은 단위는 맞는 자리마다 함께 읽는다(`3+개월`, `3+개 월`). 그 뒤에 조사 사슬과 서술격 이다가 이어진다(`3+개+이+다`). 수와 단위의 그래프는 반박이 없어 성립 1이고, 수 뒤 조각의 선호는 표의 항목 수로 고르게 나눈 값이다(표에 횟수가 없다). 단위 뒤의 `~`는 뒤에 수가 오면 앞 어절을 닫는 조각이다(`1+월+~[범위] 3+월`).
- 단위 앞의 수(`numerals`, 표는 `numeral_table.go`). 규칙은 단위에 있다(예외 `PieceIs`, 기준 `PieceNum`에 `Not`). 수로 치는 것은 숫자 열, 붙여 쓴 한글 수사, 표의 영문 글자다. 고유어 수사는 단위 앞 꼴 한·두·세·네·다섯·여섯·일곱·여덟·아홉(혼자, 또는 `열` 뒤: `열두`), 혼자 서는 열·스무·몇·여러다. 한자어 수사는 일~구와 십·백·천·만·억·조를 글자마다 읽되 일~구 둘이 맞닿지 않는 열이고(`삼십`, `이백`, `삼천오백육십칠`. 길이 한도는 없다), `수`는 맨 앞에서 큰 수 앞에만 선다(`수십`). 영문 글자는 `N` `n` `X` `x` `K` `k`가 그 글자 하나로 열일 때만이다(`N개`; `Nx개`, `L2개`는 아니다). 이런 수는 줄기로 `한[수]+개[단위:개]`처럼 찍히고, 선호는 표의 항목 수로 고르게 나눈 값이다. 숫자 열 뒤의 십·백·천·만·억·조는 조각 `큰 수:<꼴>`로 단위 앞에 선다(`7[수]+만[큰 수:만]+장`, `3+천+만+원`, `10+억`). 한글 수사나 영문 글자 뒤의 단위는 뒤에 글자가 그대로 이어지면 기각한다(예외 `PieceRight`): 조사 사슬, 서술격 이다, `째`가 오거나 거기서 단위(띄어쓰기 사이)가 끝나야 한다(`사회적`의 `회`는 단위가 아니다). 낱말 표가 있을 때 숫자 열 뒤의 단위는 글자가 이어져도 어절을 닫는다(`10+개 언어`). 한 음절 한글 수사와 단위를 합친 글자열이 낱말 표의 낱말이거나 줄임 꼴이면 반박 `PieceIs`(기준 `PieceWhole`)가 단위 풀이를 뒤로 보낸다(`이건`, `세대`, `조건`은 통짜 낱말이 먼저 선다). 낱말 표가 없으면 한자어 한 음절 수사(일~구)는 홀로 수 자리에 서지 못한다(예외 `PieceIs`, 기준 `PieceLone`). 고유어 수(한, 두, 세, 네, 몇 …)는 그대로 받는다. 띄어 쓴 `세 개`는 읽지 않는다.
- 조사 사슬은 "앞 조사의 갈래 → 뒤에 올 수 있는 조사의 갈래" 표(`rule.Links`)로 판정한다. 표준 문법의 일반 규칙이고, 표에 없는 짝은 기각한다(`결+과+가`, `마당+에+서`). 사슬의 길이 한도는 없다: 갈래 표가 허락하는 대로 읽는다(`친구+에게서+부터+는+요`). 조사의 풀이마다 갈래가 따로다(`linkOf`: `에서`의 주격 풀이는 격조사, 부사격 풀이는 부사격). 예외를 더하려면 그 조사 풀이의 그래프에 예외 간선을 얹는다(`markerGraph`). 모음 뒤의 강조 `야`(`에야`)는 이 층만 읽는 `보조사:야`다. 이 층만 읽는 조사는 `ownParticles`에 있다: `은커녕`·`는커녕`(통짜 조사), 부사격 조사 뒤에만 서는 강조의 `가`(`에서+가`, 갈래 `LinkEmph`). 연결 어미 지·고·게·어 바로 뒤의 보조사 도·는·만·야는 같은 어절의 조각이다(`보+지+도`, 그래프 `사슬:맺음 뒤 보조사`). 그 짝이 표의 맺음이면(어도, 지만) 그 맺음으로만 읽는다. 묻거나 헤아리는 맺음 ㄴ지·는지·은지·ㄹ지·을지 바로 뒤의 조사도 같은 어절의 조각이다(`맞+는지+를`, `좋+은지+는`, `가+(ㄹ)지+도`, 그래프 `사슬:물음 맺음 뒤 조사`). 이 맺음으로 닫은 절은 체언처럼 쓰여 보조사 도·는·만·야와 격조사 가·를·에·와를 받는다(`askClosings`, `askParticles`). 예외는 둘이다: 앞의 맺음이 그 다섯이 아니다(`Listed`에 `Not`, 앞 조각의 이름), 조사가 그 여덟 꼴이 아니다(`Listed`에 `Not`, 조각의 꼴). 그 조사 뒤에는 사슬 표가 허락하는 조사가 더 이어진다(`하+(였)+는지+에+는`). 꾸밈 맺음과 `지`로 가른 풀이(`맞+는 지+를`)는 그대로 나란히 선다.
- 닫힌 집합 낱말(의존명사, 보조 용언, 관형사, 접속 부사)은 열쇠다. 낱말마다 그래프가 있고, 낱말 표가 없을 때 그 그래프가 판정한다: 그 집합이 뒤에 붙은 것을 받지 않으면 예외 `StemTail`이 꺾는다(보조 용언 줄기는 홀로 서지 못하고, 관형사 뒤에는 선어말·맺음이 붙지 않는다. 조사는 막지 않는다). 관형사 가운데 대명사이기도 한 `이`·`그`·`저`는 조사나 서술격 앞에 서면 이름을 대명사로 붙인다(`pronounName`: `그[대명사:그]+의`. 홀로 서면 `그[관형사:그]`). 표에 없는 토큰 열은 `새 낱말` 그래프가 판정한다(주장에 "열쇠 표에 없다"는 반박이 힘 0.5로 붙어 verdict 1/3). 표지가 붙은 새 낱말 줄기가 ㅆ 받침으로 끝나면 서지 못한다(예외 `StemCoda`, 낱말 표가 있을 때만 그래프에 건다). 단위 안의 경계 뒤에 선 통짜 새 낱말은 그 글자열이 그 자리에서 통째로 표지로 읽히면 서지 못한다(예외 `PieceIs`, 기준 `PieceMarked`: `선생님` 뒤의 `께서`). 글자열이 표지로 읽히는지는 `marked`가 읽고, 서는지는 새 낱말 그래프가 그 사실과 줄기의 꼴, 뒤에 붙은 것, 표가 아는 갈래를 한 번에 받아 판정한다(`unlisted`). 낱말 표가 있으면 그런 글자열은 꼬리가 붙은 새 낱말의 줄기로도 서지 못한다(`마당 에+서`, `것 이+다`). 이음 `으`로 시작해 표지 열로 이어지는 줄기도 그렇다(`으+며`, `으+로`, `으셨+다`). 표가 아는 낱말은 낱말로 선다. 낱말 표가 없으면 줄기에는 걸지 않는다(줄기 `들`과 접미 `들`을 가를 수 없다): 그때는 그 예외를 "뒤에 표지가 붙었다"(`StemTail`)가 다시 꺾게 그래프를 짠다.
- 색인(`index`)은 표지 꼴의 마지막 토큰에서 그 표지들로 간다. 합쳐진 토큰은 토큰 그대로와 받침(ㄴ, ㄹ, ㅁ, ㅂ, ㅆ)·모음(어/아)의 열쇠 양쪽으로 찾는다(`keysAt`). 받침·모음 판정, 붙는 조건, 사슬과 칸의 순서 같은 조건식은 `pkg/rule`의 것을 `nlgeul parse`와 함께 쓴다.

## 스트림 읽기

- 단위는 띄어쓰기 사이다(앞뒤 문장 부호는 뗀다). 읽기 전에 문장을 단위로 가르는 단계(`unitsOf`)가 짝이 맞는 여닫는 기호(묶음표, 큰따옴표, 작은따옴표)를 문장 전체에서 맞춰 그 자리에서도 가른다: 여는 기호는 홀로 한 단위이고(`([여는 묶음표]`), 닫는 기호는 뒤에 붙은 조사와 한 단위다(`)[닫는 묶음표]+를`). 백틱 사이의 코드는 안의 띄어쓰기째 한 조각이고 읽지 않는다(`` `a b`[코드]+를 ``). 작은따옴표는 영문·숫자 사이에 있을 때만 줄임표로 보고 짝에서 뺀다(`it's`. 닫는 따옴표에 조사를 붙여 쓴 `…호랑이'는`은 짝이다). 짝이 없는 기호는 전처럼 단위 가장자리에서 뗀다. 단위를 읽을 때는 단위 밖을 보지 않는다.
- 토큰 자리마다 거기서 끝나는 표지 열을 색인에서 찾아 그래프를 돌린다(`tailsAt`: 조사 사슬 `chains`, 선어말 칸 `slots`, 맺음 `closings`). 기각된 것은 버린다.
- 읽기(`path`)는 어절의 연쇄다. 어절은 줄기(새 낱말 또는 열쇠)와 그 뒤 표지들이다. 표지 없는 어절은 닫힌 집합 낱말이거나 단위의 끝에서만 선다.
- 성립은 조각 verdict의 최솟값, 선호는 조각마다 log10(관측 횟수 ÷ 표의 총 횟수)의 합이다. 횟수가 없는 표지와 줄기는 음절마다 log10(1/11172)로 친다. 표지의 횟수는 이 층만 읽는 표(`counts_table.go`)에 꼴마다 따로 있고(이형태 짝 이/가, 을/를, 면/으면도 저마다의 횟수. 다만 세요/으세요, 십시오/으십시오, 어다가의 세 꼴, ㄴ들/은들, ㅂ시다/읍시다, ㄹ뿐더러/을뿐더러, 이라고/라고, 아/야, 이시여/시여, 이든가/든가는 한 값을 함께 쓴다. 횟수의 출처와 확보일은 이 저장소에 기록이 없다), 합에는 같은 꼴을 풀이가 몇이든 한 번만 더한다. `nlgeul parse`가 읽는 문법 표의 횟수 칸은 그대로다. 합쳐진 어/아와 ㅆ은 풀어 쓴 꼴(아, 었)의 횟수로 친다. 자리마다 가장 나은 읽기 16개를 남긴다(`beam`). 끝에 닿은 읽기도, 단위 전체를 앞 단위에 붙는 표지로 읽은 풀이와 합쳐 나은 것부터 16개까지만 올린다(글줄이 같은 읽기는 한 번만). 16이라는 값의 근거는 기록된 것이 없다.
- 줄기 끝 음절에 조각이 합쳐진 읽기는 줄기를 본디 꼴로 되돌려 찍고(열쇠도 그 꼴로 찾는다), 합쳐져 있던 조각은 괄호에 본디 꼴로 적는다: `마시+(ㄴ)다`, `하+(ㅂ)니다`, `가+(았)+다`, `하+(여)서`, `쓰+(어)`(`restores`, `fusedTails`). ㅏ·ㅓ는 같은 모음의 줄기와 ㅡ가 빠진 줄기 두 갈래로 올린다(`써` → `써+(어)`, `쓰+(어)`). ㅡ가 빠진 줄기는 낱말 표가 르·러 불규칙으로 적은 줄기가 아니고 어/아가 ㅡ 앞 음절의 모음에 맞을 때만 선다(그래프 `줄기:되돌린 끝 음절`의 예외들, `restored`: `따르+(아)`, `치르+(어)`는 서고 `모라`를 `모르+(아)`로 읽지 않는다. 한 음절 줄기는 어뿐이다). `놔`는 `놓+(아)`로도, 낱말 표가 있으면 `마`는 `말+(아)`로도 되돌린다(`하지 마`, `마라`). 줄기 끝 음절 `되` 뒤에서는 글자에 없는 어도 읽는다(`unspelt`, `unspeltAt`: `되+(어)도`, `되+(어)서`, `되+(어)야`, `되+(어)+요`, `되+(었)+다`). `돼도`, `돼서`, `됐다`로 적어야 하는 꼴(한글 맞춤법 제35항 붙임 2)을 `되도`, `되서`, `됬다`로 적은 것이고, 가·서·내·세처럼 겉으로 안 바뀌는 합침과 같은 자리에서 같은 값으로 읽는다(홀로 선 `(어)`는 흔적 없는 조각의 값을 치른다). `되+도[보조사:도]` 같은 다른 풀이는 그대로 선다. 영문·숫자 바로 뒤의 음절에서는 조각을 떼지 않는다(같은 그래프의 예외 `PieceAfter`. 하·되·이는 뗀다: `push하+(여)`, `latinBases`). 겉으로 안 바뀌는 모음 합침(가, 서, 내, 세)은 뒤에 조각이 더 있거나 단위의 끝이거나 바로 뒤가 보조 용언 줄기일 때만 읽는다(`가보다` → `가+(아) 보+다`). 보조 용언 줄기의 끝 음절에 조각이 합쳐진 글자여도 된다(`auxHead`: `빼줘` → `빼+(어) 주+(어)`, `가볼까`). 낱말 표가 있으면 합쳐진 어/아와 았/었은 흔적이 있든 없든 앞말이 표의 용언 줄기일 때만 선다(`asksStem`, 그래프 `앞말:용언`. 해·했은 묻지 않는다). ㅕ는 ㅣ+어(`마셔` = 마시)와, 낱말 표가 있으면 줄기 자신의 ㅕ+어(`켜` = 켜)로 푼다. `--cuts`의 자리는 원문 토큰 자리 그대로다.
- 맺음은 parse와 함께 쓰는 맺음 표에, 이 층만 읽는 표(`moreClosings`)를 더해 읽는다: 사전에 어미로 올라 있는 되, 어야지, 어야만, 어다가, 다면서·다며·다니 무리, 길래, 든가, ㄴ들, ㄹ망정, ㄹ지라도, ㄹ뿐더러, ㄹ세라, 으라고, 다만, 건만, 느냐고, ㄴ지라, 답니다 무리다. 낱말 표가 있으면 표의 용언 줄기 뒤에서 이름 꼴 맺음 기도 읽고(`gatedClosings`), 그 바로 뒤의 조사 사슬을 같은 어절의 조각으로 읽는다(그래프 `사슬:이름 꼴 뒤 조사`: `있+기+는`, `받+기+에+는`). 맺음 바로 뒤의 보조사(도·는·만·야)는 지·고·게·어/아와 어서·아서·면서 뒤에서 읽는다(`먹+어서+는`).
- 낱말 표가 있을 때 새 낱말 줄기가 서지 못하는 곳: 표지 꼴 줄기(`marked`. 받침을 뗀 `으`도 이음 으로 본다: `으+(ㄹ)걸`), 표나 닫힌 집합이 용언 아닌 갈래로만 아는 낱말이 서술어 꼬리 앞에 선 것(새 낱말 그래프의 예외 `StemKind`. "표에서 용언 줄기이기도 하다"와 "뒤가 서술어 꼬리가 아니다"가 그 예외를 꺾는다: `뭐+냐`, `거+네`). 경계 뒤의 통짜 새 낱말은 글자열이 표지 한 열이나 표지 두 열의 이음으로 읽히면 서지 못한다(`twoRuns`: `는게`).
- 낱말 표가 있을 때 새 낱말 줄기는 ㅆ 받침으로 끝나지 못한다(새 낱말 그래프의 예외 `StemCoda`): 표에 없는 줄기에 표지(조사, 선어말, 맺음)가 붙은 읽기에서 줄기의 마지막 음절이 ㅆ 받침이면 서지 못한다(`떨어졌+다`, `떨+어 졌+다`). ㅆ 받침으로 끝나는 줄기는 `있`과 그것으로 된 낱말뿐이고(낱말 표에 있다) 나머지 ㅆ은 선어말 았·었·겠이다. 줄기는 조각이 합쳐지기 전의 꼴로 본다. 표지 없는 통짜 새 낱말(`떨어졌다`)과 표가 아는 줄기(`있+다`)는 그대로 선다.
- 낱말 표가 있을 때 꾸밈꼴 바로 뒤에 용언이 오지 못한다(`afterAdn`, 갈래 그래프 `열쇠:동사`·`열쇠:형용사`의 예외 `PieceIs`, 기준 `PieceAdn`): 한 단위 안에서 꾸밈 맺음으로 끝난 낱말 바로 다음 낱말이 낱말 표의 동사·형용사 줄기로 읽히면 그 읽기는 서지 못한다(`떨+(ㄹ) 어지+(었)+다`). 의존 명사에 하다·싶다가 붙은 보조 용언의 줄기(`boundAux`: 듯하, 듯싶, 만하, 법하, 뻔하, 성싶, 성부르, 성하, 척하, 체하, 양하)는 그 예외를 다시 꺾는 예외 `Listed`로 선다(`아+는 척하+(였)+다`). 그 낱말 자신이 꾸밈꼴·이름꼴이면 예외 `PieceIs`(기준 `PieceTurned`, 사실은 `namesForm`이 읽는다)가 같은 예외를 꺾는다. 다음 낱말이 새 낱말, 체언, 관형사, 부사이면 걸리는 예외가 없다. 꾸밈꼴이 앞에 섰는지는 읽기마다 다른 사실이라, 꾸밈꼴이 끝나는 자리에서 그 사실을 넣어 갈래 그래프에 다시 묻고 마지막 어절이 꾸밈꼴인 읽기에만 그 답을 쓴다. 단위를 넘어선 이웃은 보지 않는다. 갈래 그래프가 줄기를 판정하는 둘째 겹부터다. 관형사 바로 뒤에도 용언이 오지 못한다(같은 두 그래프의 예외 `PieceIs`, 기준 `PieceDet`): 한 단위 안에서 표지 없이 선 낱말의 풀이가 관형사뿐이고(`determiner`: `이[관형사:이]`, `세[열쇠:관형사]`. 체언이기도 한 `열쇠:체언|관형사`는 아니다) 바로 다음 낱말이 낱말 표의 동사·형용사 줄기나 보조 용언 줄기로 읽히면 그 읽기는 서지 못한다(`세 보+(아)`). 그 낱말 자신이 꾸밈꼴·이름꼴이면 선다(`어떤 마시+는`, 예외 `PieceTurned`). 의존 명사에 하다·싶다가 붙은 보조 용언은 꾸밈꼴 뒤에만 붙으므로 관형사 뒤에서는 꺾지 않는다. 홀로만 서는 낱말(감탄사 들, 그래프 `열쇠:홀로`)은 꾸밈 맺음으로 끝난 낱말 바로 뒤에도 관형사 바로 뒤에도 서지 못한다(`aloneExcept`, 예외 둘이고 꺾는 것이 없다. 표지 없는 낱말을 세우는 `whole`이 같은 `afterAdn`으로 묻는다). 체언을 꾸미는 말 뒤에는 체언이나 그 체언을 꾸미는 다른 말이 오고, 감탄사는 둘 다 아니다. 부사는 뒤의 관형사·꾸밈꼴을 꾸밀 수 있어 막지 않는다.
- 대명사 네·내·제는 이 층의 표(`pronounWords`)에 있고, 낱말 표가 있으면 체언 갈래로 친다(`네+가`).
- 단위 전체가 조사 사슬이나 서술격의 꼬리이면 앞 단위에 붙는 표지로 읽은 풀이를 하나 세운다(`attached`, `loneOf`: `+로[부사격:로]`, `+이[서술격:이]+(ㄴ)데[맺음:ㄴ데]`). 줄기 없는 어절이고 `Attach`가 참이다. 꾸밈 꼴 뒤에서 띄어 쓴 게·건·걸은 `거+(이)`로 읽는다. 띄어 쓴 `테니까`, `텐데`도 `터+(이)+니까`로 읽는다(단위의 머리가 그 글자이고 나머지가 그 뒤의 꼬리일 때). 줄기가 이 단위에 없으므로 성립은 새 낱말보다 높지 않고, 낱말이기도 한 글자(이, 가, 만)는 그 낱말 풀이와 경합한다.
- 남은 읽기가 모두 합의한 자리에서 끊는다(`agreed`). 끊긴 구간마다 읽기가 하나면 확정, 여럿이면 경합 묶음이다(`bundles`). 찍을 때 확정은 한 줄, 경합은 머리 줄과 갈래마다 한 줄이다(`render`).

- 본용언의 어/아 꼴 바로 뒤에 붙여 쓴 보조 용언 줄기(닫힌 집합의 주·보·버리·놓·두·있, 낱말 표가 있으면 가·내·드리도)는 그 사이 경계의 값을 돌려받는다(`grow`). 그 줄기 뒤가 서술어 꼬리(선어말·맺음)일 때만이다: 같은 글자가 체언으로 서서 조사를 받으면(`주+는[보조사:는]`) 돌려받지 않는다. `지`(어지다)와 `하`(어하다)는 늘 붙여 쓰므로 경계를 세우지 않고 같은 어절의 조각으로 읽는다(`helped`: `지우+(어)+지+(ㄴ)다`, `예쁘+(어)+하+(ㄴ)다`). 낱말 표가 있고 본용언이 표의 용언 줄기일 때만이다.

`--trace`는 걸린 토큰 열, 그래프, verdict, 기각 이유를 찍고, `--cuts`는 측정용으로 읽기마다 어절 끝 자리만 찍는다.

## 기호와 영문·숫자 열

낱말 표와 무관한 구조 규칙이다(낱말 표가 없어도 적용한다).

- 라틴 문자, 숫자, 밑줄이 이어진 열은 조각 하나다(`runsOf`). 그 안에서는 어절이 시작하거나 끝나지 않고, 그 안의 부분 문자열로 낱말을 찾지 않는다. 표에 없는 열은 `열:영숫자` 그래프가 판정한다(주장에 "열쇠 표에 없다"는 반박이 힘 0.25로 붙어 verdict 0.6, 자리 채움 값). 열 뒤에 한글 표지가 붙는다(`L2+의`).
- `.`은 풀이마다 그래프가 있다(`dotGraph`). 양쪽이 열인 점을 잇는 풀이 넷과, 앞 어절을 닫는 풀이 둘이다.

| 그래프 | 주장 | 예외 |
|---|---|---|
| `파일명:.` | 이름과 확장자를 잇는다 | 양쪽이 영숫자 열이 아니다, 오른쪽이 확장자 목록(`extensions`)에 없다 |
| `도메인:.` | 도메인의 마디를 잇는다 | 양쪽이 영숫자 열이 아니다, 맨 오른쪽 마디가 최상위 도메인 목록(`topDomains`)에 없다 |
| `소수점:.` | 수의 소수점이다 | 양쪽이 숫자가 아니다, 숫자 마디 둘이 아니다 |
| `버전:.` | 버전 번호의 마디를 잇는다 | 양쪽이 영숫자 열이 아니다, 마디가 모두 숫자(첫 마디는 v로 시작해도 됨)가 아니다. 점이 하나인 수는 소수점과 버전의 경합이다(`1.2[소수점|버전]`) |
| `마침표:.` | 문장이 끝났다 | 양쪽이 영숫자 열이다(`MarkBoth`), 점이 이어진다 |
| `줄임표:.` | 말을 줄였다 | 점이 하나뿐이다 |

- 잇는 풀이가 하나라도 서면 양쪽 열이 한 덩어리(`atom`)가 되고 줄기 뒤 대괄호에 선 풀이들이 적힌다(`task.py[파일명|도메인]+에`, `v1.2.3[버전]`). 둘 이상 서면 이름을 `|`로 잇는다. 고를 근거가 없어 고르지 않는다.
- 닫는 풀이는 앞 어절의 마지막 조각이 된다(`했+다[맺음:다]+.[마침표:.]`). 단위의 끝에 붙은 점은 단위의 줄들 뒤에 한 줄로 찍는다(`.[마침표:.]`, `...[줄임표:.]`). 단위 앞뒤의 다른 문장 부호는 전처럼 뗀다.
- 두 영숫자 열 사이의 빗금과 붙임표는 이름을 잇는다(`nameSigns`: `a/b[경로]`, `h-Cat[붙임]`). 양쪽이 숫자면 수의 기호다(`11/10[날짜|나눔]`, `10-20[범위|빼기]`). 아는 낱말 사이의 빗금과 붙임표는 그 낱말들을 한 줄기로 묶는다(`bound`: `입력/출력[대비:/]`, `원-달러[붙임:-]+를`). 낱말 표가 있고 마디가 모두 아는 낱말이거나 영숫자 열일 때만이다. 묶인 줄기의 선호는 마디마다 따로 쳐서 더한다(`partsPref`. 영숫자 열 마디는 토큰 하나다). 원자 하나인 줄기(`a/b[경로]`, `h-Cat[붙임]`)는 마디로 쪼개지 않고 토큰 하나로 친다.
- 문장의 낱말이 아닌 입력으로 시작하는 단위는 그 부분이 조각 하나다(`special`, `wholeAtom`): 주소(`http://`, `https://`), 전자우편, 경로(머리가 `/`·`~/`·`./`·`../`이거나 이름 사이 빗금이 둘 이상), 명령의 옵션(`-x`, `--xx`). 한글이 아닌 마지막 글자까지가 그 조각이고 안에서 낱말을 찾지 않는다. 뒤에 조사가 붙는다(`~/a/b[경로]+를`, `--xx[옵션]`).
- 단위 앞뒤의 기호 가운데 이름에 드는 것은 떼지 않는다(`trimUnit`, `headKept`): 경로의 머리와 끝의 빗금, 옵션의 붙임표, 영문 앞의 `@` `#` `$` `_` `.`(`@name`, `.env`).
- 한글과 영문·숫자 열이 맞닿은 자리는 표지가 없어도 어절이 끝날 수 있는 자리다(`change`): `toulmin엔진` → `toulmin` / `엔진`.
- 선호를 셀 때 한 덩어리는 토큰 하나로 친다(`tokens`).

## 낱말 표

`Options.Words`(명령에서는 `--words` 또는 환경 변수 `NLGEUL_WORDS`)로 낱말 표를 주면 줄기를 그 표에서 찾는다. 표가 없으면 위에 적은 대로만 읽는다. 표의 형식은 탭으로 나눈 칸 넷(검색 키, 갈래, 불규칙 유형, 횟수)이고 `#`으로 시작하는 줄은 건너뛴다. 불규칙 유형은 ㄷ, ㅅ, ㅂ, ㅎ, 르, 러, 우를 읽는다. 낱말은 표의 줄이고 그래프가 아니다. 줄기를 표(`map`)에서 찾아 그 갈래·횟수·길이를 갈래별 그래프 여섯 개(`열쇠:체언`, `열쇠:동사`, `열쇠:형용사`, `열쇠:부사`, `열쇠:관형사`, `열쇠:홀로`)에 넘긴다(`stemVerdict`, 같은 사실은 한 번만 평가해 둔다. 기억의 열쇠는 그래프에 준 사실 전부다). 세 겹으로 쓴다(`--layers`로 겹을 줄여 잴 수 있다).

1. 여부: 표에 있는 줄기(풀어 쓴 꼴)는 아는 낱말이다. 없는 토큰 열은 그대로 새 낱말이다. 선호는 log10(횟수 ÷ 표의 총 횟수)다. 갈래가 둘인 키는 뒤를 받는 갈래의 횟수를 쓴다(`taken`: 명사 `작`은 형용사 `작`만큼 흔하지 않다).
2. 갈래 맞춤과 증거의 세기: 갈래별 그래프가 줄기를 판정한다. 주장 "이 줄기는 아는 낱말이다"를 예외 `rule.StemTail`(갈래가 뒤에 붙은 것을 받지 않는다)이 꺾고, 동사·형용사 그래프에서는 예외 `rule.PieceIs`(바로 앞 낱말이 꾸밈 맺음으로 끝난다, 바로 앞 낱말이 관형사다)도 꺾고, 홀로 그래프에서도 그 두 예외가 꺾고, 반박 `rule.SeenFew`(관측이 적다. 횟수 0인 줄도 한 번과 같이 친다)와 `rule.ShortKey`(한 음절이다)가 낮춘다. 닫힌 표의 구어 꼴(`spoken`: `것`을 구어로 이르는 `거`)에서는 예외 `rule.Listed`가 반박 "관측이 적다"를 꺾는다: 글말에서 센 횟수가 적다는 것은 구어 꼴에 불리한 증거가 아니다(`거[의존명사:거]`의 성립이 한 음절 반박만 받은 값이 된다. 선호는 그대로다). 줄기의 낱말이 단위 전체이면(줄기가 단위의 첫머리에서 시작하고 그 뒤가 그 줄기의 표지뿐이다) 예외 `rule.PieceIs`(기준 `PieceSole`)가 반박 "한 음절이다"를 꺾는다: 그 반박의 까닭은 한 음절 낱말이 긴 글자열 속에서 우연히 겹치기 쉽다는 것인데, 띄어쓰기가 낱말의 양 끝을 정해 준 자리에는 그 까닭이 없다(`하+자`, `가+는`의 줄기 성립이 1이 된다. 단위 안에 낱말이 둘 이상이면 전과 같다). 성립은 그래프가 낸 값 그대로다: 두 반박이 다 걸려도 새 낱말보다 조금 위다. 체언(명사, 대명사, 수사, 식별자)은 홀로 서거나 조사를 받고, 동사 줄기는 선어말과 모든 맺음을, 형용사 줄기는 동사 전용 맺음(`verbClosings`: 현재 ㄴ다/는다, 청유, 목적·의도)을 뺀 맺음을 받고 둘 다 홀로 서지 못하고, 부사는 홀로 서거나 보조사를 받고, 관형사와 그 밖은 홀로 선다. 닫힌 집합 낱말도 같은 판정을 받는다. 닫힌 집합 낱말의 이름(`관형사:이`)은 그 집합의 갈래로 섰을 때만 찍는다(`ownName`): 조사 앞의 `이`는 낱말 표의 체언으로 선 것이라 `이[열쇠:체언]+가`로 찍고, 두 집합에 든 `두`는 선 쪽의 이름만 찍는다(`두[보조 용언:두]+고`). 홀로 설 수 있는 아는 낱말은 단위 안에서도 표지 없이 어절이 된다.
3. 구조 값: 단위 안의 경계, 글자에 흔적이 없는 조각, 줄기에 값을 매긴다(`costBoundary`, `costUnseen`, `costPiece`). 색인의 표지(조사, 선어말, 맺음, 단위, 기호)는 조각 값을 치르지 않는다. 구조 값은 낱말 표가 없을 때도 매긴다.

불규칙 용언(`irr_table.go`, `changed`, `variants`). 낱말 표의 용언 줄기가 꼬리 앞에서 바뀐 꼴은 그 꼬리와 묶어서만 읽고, 본디 줄기로 찍는다. 바뀐 꼴은 홀로 줄기가 되지 않는다. 바뀐 꼴이 다른 낱말과 같으면 둘이 나란히 선다.

| 유형 | 바뀐 꼴 | 나오는 자리 | 예 |
|---|---|---|---|
| ㄹ 탈락 | 살 → 사 | ㄴ·ㅅ으로 시작하는 꼬리, 합쳐진 ㄴ·ㄹ·ㅂ 앞. 유형 표시와 무관하게 ㄹ 받침 줄기 전부 | `살+(ㄴ)다`, `알+는` |
| ㄷ | 듣 → 들 | 어/아, 으가 든 꼴 앞 | `듣+었+다`, `듣+으+니` |
| ㅅ | 짓 → 지 | 어/아, 으가 든 꼴 앞 | `짓+어`, `짓+은` |
| ㅂ | 돕 → 도우 (돕·곱은 도오도) | 으를 받는 꼬리의 모음 뒤 꼴, 합쳐진 어/아 앞 | `덥+(어)서`, `돕+(아)` |
| ㅎ | 파랗 → 파라, 파래 | 으를 받는 꼬리와 네 앞 / 합쳐진 어 | `파랗+(ㄴ)`, `그렇+(어)` |
| 르 | 모르 → 몰르 | 합쳐진 어/아 | `모르+(아)` |
| 러, 우 | 이르 → 이르르, 푸 → 프 | 합쳐진 어 | `이르+(어)`, `푸+(어)` |

ㄷ·ㅅ 뒤의 으가 든 꼴은 본디 줄기의 끝 음절로 판정한다(`irrTails`, `linked`: `지은`의 은은 `짓` 뒤라 선다). 표가 규칙이라 적은 그러·이러·저러·어쩌의 그래 꼴은 닫힌 표(`eoStems`)로 읽는다. 받침 하나뿐인 맺음(ㄴ, ㄹ, ㅁ)은 낱말 표가 있으면 앞말이 표의 용언 줄기일 때 어느 음절 밑에서든 읽고(`예쁘+(ㄴ)`), ㄹ 받침 줄기의 ㅁ은 ㄻ에서 뗀다(`살+(ㅁ)`). 체언 + 이 빠짐으로는 열지 않는다.

반박의 힘, 문턱, 구조 값(`forceNew`, `seenEnough`, `forceFew`, `forceShort`, `forceWhole`, `forceClash`, `forceDropAdn`, `cost…`)은 자리 채움 값이다. 몇 가지 값을 문장 묶음에 재어 고른 것도 있으나 조각의 정답이 있는 자료로 맞춘 값은 아니다. 낱말 표가 있으면 읽기의 차례는 선호 + log10(성립)이다(`before`). 성립이 낮은 읽기도 남고 뒤로 갈 뿐이다.

그래프는 낱말 표 없이 468개(간선 957), 낱말 표가 있으면 517개(간선 1090)다.

# token

`nlgeul token`의 읽기. 토큰(음절) 스트림을 조각으로 가르고 어절로 끊어 올리는 데까지만 한다(실험, 설계는 작업 문서 `token-stream-algorithm.md`). 문장성분은 정하지 않는다. `Reader.Bundles(문장)`이 결과를 구조로 돌려주고, `Reader.Lines(문장, trace)`가 같은 구조를 글줄로 찍어 돌려준다.

## 올려 보내는 구조

위층(어절 층)은 글줄을 쪼개지 않고 이 구조를 받는다. `Lines`와 `LinesHead`는 이 구조를 찍을 뿐이다(`render`, 타입마다 `String`). 찍는 길은 하나다. `LinesHead(문장, 추적, head)`는 경합 하나의 후보 줄을 앞의 head개까지만 찍고, 더 있으면 마지막 후보 줄 다음에 후보 줄과 같은 들여쓰기로 `(k개 생략됨)`을 찍는다(k는 찍지 않은 후보 수). head가 0이면 전부 찍고, `Lines`는 `LinesHead(…, 0)`이다. 줄이는 곳은 `render(b, head)` 하나이고 후보를 만드는 쪽과 `Bundles`는 건드리지 않아 `Bundles`는 head와 상관없이 후보를 전부 돌려준다. 추적 줄과 경합 머리 줄은 줄이지 않는다.

```go
r, _ := token.New(token.Options{Words: "words.tsv"})
for _, b := range r.Bundles("작은 곰이 물을 마신다.") {
	best := b.Branches[0]
	last := best.Words[len(best.Words)-1].Parts
	_ = last[len(last)-1].Name // 끝 조각의 풀이: {꾸밈 은} …
}
```

| 타입 | 칸 | 뜻 |
|---|---|---|
| `Bundle` | `Unit` | 문장의 몇째 단위에 든 경합인가(0부터) |
| | `Glued` | 문장에서 이 경합과 바로 앞 경합 사이에 빈칸이 없는가(문장의 첫 경합은 거짓. 한 단위 안의 둘째 경합부터는 참이고, 단위의 첫 경합은 앞 단위 뒤에 빈칸이 없으면 참). `Reader.Bundles`가 채우고 화면 출력(`Lines`, `render`)에는 찍지 않는다. `+`로 갈린 단위와 여닫는 기호에서 갈린 단위·경합이 붙어 있었는지를 알려 준다 |
| | `Text` | 그 구간의 글자 |
| | `Branches` | 갈래들, 나은 것부터. 하나면 확정, 둘 이상이면 후보가 둘 이상인 경합(`Contest()`) |
| `Branch` | `Words` | 어절들. 단위 안에 경계가 선 갈래는 둘 이상이다 |
| | `Verdict`, `Pref` | 성립(조각 verdict의 최솟값), 선호 |
| `Eojeol` | `Parts` | 조각들. 줄기가 먼저, 그 뒤가 표지 |
| | `End` | 단위 안에서 이 어절이 끝나는 자리(토큰 수) |
| | `Attach` | 줄기 없이 표지만 있는 어절인가. 띄어 쓴 표지 단위(`로`, `에서`, `인데`)를 앞 단위에 붙는 표지로 읽은 것이고, `+로[부사격:로]`처럼 `+`로 시작하게 찍는다 |
| `Part` | `Text` | 글자. 줄기는 찾는 꼴(되돌린 줄기, 불규칙의 본디 줄기, 줄임이 가리키는 낱말, 오표기 줄기의 바른 꼴) |
| | `Hidden` | 글자에 안 보여 풀어 쓴 부분(`(ㄴ)다`의 `ㄴ`, 빠진 `(이)`의 `이`) |
| | `Name` | 풀이 하나. 한 조각에 풀이가 하나씩이고, 풀이가 여럿인 자리는 후보가 따로 나온다(`가[주격:가]`와 `가[보격:가]`). 이름 없는 줄기는 빈 `Name{}`이다 |
| | `Stem` | 줄기인가(아니면 표지: 조사, 선어말, 맺음, 단위, 기호) |
| | `Unseen` | 글자에 흔적이 전혀 없는 조각인가 |
| | `Depth` | 여닫는 기호의 깊이(`([열기:2]`와 `)[닫기:2]`는 2: 바깥에 묶음 하나가 열려 있다)와 제목의 단계(`##[제목2]`는 2). 그 밖에는 0 |
| | `Written` | 틀린 표기로 적힌 줄기 또는 표지가 글자에 적힌 꼴. 줄기는 낱말 표 또는 이 층의 닫힌 표가 다른 낱말의 틀린 표기로 적은 것(`맞기`, `꺼`. 합쳐진 조각을 떼어 되돌린 꼴, 빗금·붙임표로 묶인 줄기는 묶음 전체 `입력/역활`), 표지는 닫힌 표의 틀린 맺음(`ㄹ께`, `읍니다`). 그 밖에는 빈 문자열. 찍을 때만 이름 끝에 `,오타정정:맞기`로 덧붙고 `Name`에는 들지 않는다. 그 부분의 `Text`는 바른 꼴(표지는 `게`, `Hidden`은 `ㄹ`) |
| `Name` | `Kind`, `Form` | 풀이의 갈래(`주격`, `꾸밈`, `열쇠`, `맺음`, `수`, `경로` …)와 꼴(`가`, `은`, `체언` …). 갈래만으로 다인 것은 꼴이 비어 있다 |

- 한 단위의 경합은 이 차례로 나온다: 글자 앞에 붙은 기호마다 하나, 후보들이 모두 합의한 구간마다 하나, 글자 뒤에 붙은 기호마다 하나(`?[물음표]`, `.[마침표]`는 줄기 없는 조각 하나짜리 어절이다). 경합의 `Text`를 차례로 이으면 빈칸을 뺀 문장 그대로다: 입력 글자는 하나도 빠지지 않는다.
- 표가 모르는 줄기(새 낱말)는 `Name`이 비어 있다. 낱말 표가 준 갈래는 후보마다 하나다(`지금[열쇠:체언]`과 `지금[열쇠:부사]`는 두 후보다. 각각 `{열쇠 체언}`, `{열쇠 부사}`).
- 수, 주소·경로·옵션, 여닫는 기호와 코드는 줄기 조각이고 이름이 그것을 말한다(`{수}`, `{경로}`, `{열기 1}`, `{닫기 2}`, `{코드}`). 여닫는 기호의 깊이는 이름의 꼴(`"1"`)과 `Depth`(1) 양쪽에 있다. 이름이 붙지 않은 기호(`->`, `*`)는 이름 없는 줄기 조각 하나짜리 경합이고 글자 그대로 찍힌다.
- 추적(`--trace`)은 구조에 없다. `Lines`(`LinesHead`)가 단위마다 구조 앞에 찍는다.

## 색인과 그래프

이 층의 닫힌 표 가운데 값의 나열인 것은 `data/tables/*.tsv`에 있고 `*_table.go`가 `data` 꾸러미로 읽어 변수를 만든다(줄 읽기는 `shortOf`, `contractOf`, `pairOf` 들). 변수 이름은 파일에 남아 있다. 틀린 줄이 있으면 프로그램이 시작할 때 파일 이름과 줄 번호를 대고 멈춘다. 코드에 남은 표도 있다(수사, 불규칙 용언, 합쳐진 글자 들). 표 파일마다의 칸과 줄을 더하는 법은 [data/README.md](../../data/README.md)에 있다.

- 표지 풀이 하나에 toulmin 그래프 하나다(`markerGraph`). 그래프는 문법 표의 한 줄(`parse.ParticleMarkers`, `parse.ClosingMarkers`, 선어말 칸 `slotRows`)과 그 표지로 끝나는 닫힌 집합 낱말 목록에서 찍어낸다. 이름은 `주격:이`, `보조사:은`, `꾸밈:은`, `선어말:었`, `맺음:지만` 꼴이다.
- 그래프의 주장은 "이 자리의 이 토큰 열은 이 표지다"(`rule.PieceRead`)이고, 구조를 보는 예외가 그것을 꺾는다: 앞에 줄기가 없다(`PieceIs`, 기준 `PieceStem`에 `Not`), 앞 토큰의 끝이 안 맞는다(`PieceAfter`), 조사 사슬에 맞지 않는다(`ChainLinks`), 선어말 칸의 순서(`SlotOrder`), 받침만 붙은 꼴을 읽는 음절이 아니다(`Listed`에 `Not`, 낱말 표가 없을 때만), 통째로 닫힌 집합의 낱말이다(`Listed`). 어/아/여로 시작하는 조각이 앞 모음과 어긋나면 반박 `PieceClash`가 낮춘다(`먹아`는 지우지 않고 뒤로 보낸다). 규칙 함수는 모두 `pkg/rule`의 것이고 기준만 다르다: 참/거짓 사실 하나를 보는 판정은 `PieceIs`, 목록에 있는지 보는 판정은 `Listed` 하나가 기준으로 갈라 맡고, 반대 방향은 기준 `Not`으로 준다. 예외는 왜 꺾는지를 그 노드에 싣고(`except`), `--trace`는 그 노드의 이유를 찍는다.
- 풀이는 후보마다 하나다. 조사·선어말·맺음은 풀이(색인 항목)마다 조각이 따로이고(`groupAt`의 열쇠에 이름이 든다) 사슬은 풀이마다 제 갈래로 이으며 앞말 판정(`gate`)도 풀이마다 받는다. 낱말 표의 줄기는 갈래마다 후보가 따로이고(`stepsOf`, `knownReads`) 그 갈래의 그래프가 낸 성립과 그 갈래의 관측 횟수가 쓰인다(`taken`). 갈래 그래프가 기각한 갈래의 후보는 나오지 않는다. 닫힌 집합 낱말이 두 집합에 들면 집합마다, 기호로 이어진 열의 이름이 여럿이면 이름마다 후보가 따로이고 성립과 선호는 같다. 이름표 안에는 `|`가 없다.
- 받침으로 끝난 이름 뒤의 `이`(`영숙+이+가`)는 이 층만 읽는 표지 `접미:이`다(`innerSuffixes`). 받침 뒤에만 붙고 조사 사슬의 맨 앞자리이며, 뒤에 조사가 이어질 때만 선다(예외 `PieceIs`, 기준 `PieceLast`). 그래서 `고양이가`는 `고양이+가`와 `고양+이+가`가 함께 올라간다. `nlgeul parse`의 조사 표에는 없다.
- 서술격 이다(`morphemes.md` 2절)는 줄기 `이`의 그래프 `서술격:이`가 읽는다(`addCopula`, `copulas`). 주장은 "이 `이`는 체언 뒤 이다의 줄기다"이고, 예외는 앞에 줄기가 없다와 이 바로 뒤에 선 맺음이 이다에 붙지 않는 것이다(`Listed`, 맺음 표의 표시). 이 뒤에 선어말이 먼저 서면 그 선어말을 보므로 그런 맺음도 선어말 뒤에서는 선다(`firstName`: `학생+이+었+습니다`, `학생+이+었+는데`). 맺음 아래에 합쳐진 꼴은 풀어 찍는다(`학생+이+(ㅂ)니다`, `학생+이+(ㄴ)`, `문제+이+(었)+다`). 모음 뒤에서 이가 빠진 꼴은 그래프 `서술격:이(빠짐)`이 2절에 적힌 맺음(다, 고, 며, 면, 지만, ㄴ, ㅂ니다) 앞에서만 읽고 `학교+(이)+다`로 찍는다. "모음 뒤"와 "이가 빠지는 맺음의 목록에 있다"는 둘 다 그 그래프의 예외다(`PieceAfter`, `Listed`에 `Not`. 목록은 `droppable`이고 낱말 표가 있으면 `droppableKnown`을 더해 그래프를 짠다). 이와 맺음 사이에 선어말이 끼면 빠진 이로 읽지 않는다. 낱말 표가 있으면 네·냐·니·라·거든·구나·군·야·니까·죠·냐고·더라도·거나·든지·든가와 인용 꼴 라는·라며·라면서·라니 앞에서도 읽되, 앞말이 표의 체언이나 의존명사일 때만이다(`droppableKnown`: `거+(이)+네`, `뭐+(이)+냐`, `사과+(이)+라는`). 흔적이 없는 조각이라 3겹에서 값을 치른다. 이다에만 붙는 맺음(에요, 야, 라서 들)은 `서술격:이` 뒤와 줄기 `아니` 뒤에만 서고, 이다를 품은 맺음(예요)은 체언 뒤에 바로 선다. 낱말 표가 있으면 서술격 꼬리는 체언 줄기와 맞는다(`kindTails`). 횟수는 표의 452만이고, 다른 표지의 선호가 달라지지 않도록 표지 횟수의 합에는 넣지 않는다. 이가 빠진 꼴을 읽는 맺음은 다, 고, 며, 면, 지만, ㄴ, ㅂ니다, 라서, 라면, 지, ㄴ지, ㄴ데, ㄴ가, ㄹ까이고 `잖`(지+않) 앞에서도 읽는다(`학교+(이)+라서`, `학교+(이)+지+(않)+아`). 꾸밈 맺음 ㄴ 앞에서는 반박 `Listed`가 낮춘다(관형형 앞에서는 이가 대체로 빠지지 않는다). 낱말 표가 있으면 이름 꼴 맺음 기 앞에서도 읽되, 기 바로 뒤에 조사가 이어질 때만이다(`문제+(이)+기+도`, `문제+(이)+기+는`. `문제기`만으로는 읽지 않는다): 빠진 이의 그래프에 예외 "뒤가 이름 꼴 맺음이다"(`Listed`, `dropNaming`)가 있고, 그 예외를 "바로 뒤에 조사가 붙는다"(`PieceRight`)가 다시 꺾는다. 앞말은 표의 체언이어야 하고, 꾸밈 맺음 앞과 같은 반박이 낮춘다(`dropAdn`). 앞 글자가 한글 음절이 아니면(영숫자 열, 수, 코드, 파일명) 받침이 있는지 글자로 알 수 없다. 그 뒤의 빠진 이는 이다에만 붙는 맺음 `야` 앞에서만 읽는다(`abc+(이)+야`, `droppableRun`): 예외 "앞 글자가 한글 음절이 아니다"(`PieceAfter`)를 "뒤의 맺음이 그 목록에 있다"(`Listed`)가 다시 꺾는다. 이 자리에서는 앞말이 표의 체언인지 묻지 않고, 낱말 표가 있을 때만 읽는다(`야`가 `droppableKnown`의 맺음이다). 다른 맺음(다, 고, 면, 네) 앞의 영숫자 열은 전처럼 그 맺음의 줄기로만 읽는다(`abc+다`). 어하다처럼 본용언의 어/아 꼴에 붙여 쓰는 보조 `하`(`helped`)가 이 뒤에 서는 후보는 두 그래프의 예외 "뒤가 본용언에 붙여 쓰는 보조 용언이다"(`Listed`, 닫힌 표 `copulaBars`)가 기각한다. 뒤에 선 것의 이름은 `afterCopula`가 준다(`학교이어하는`은 `학교+이+어 하+는`으로만 읽고 `학교+이+(어)+하[보조:하]`로 읽지 않는다. 예쁘+(어)+하처럼 용언 뒤의 보조 `하`는 그대로다). 접미 `들`·`씩`·`끼리` 뒤에도 서술격이 선다(`afterSuffixes`, 목록은 닫힌 표 `copulaSuffixes`, 사슬 표의 갈래 `LinkCopula`): 서술격 꼬리를 읽은 자리에서 그 앞의 조사 사슬을 한 번 더 읽어 마지막 조각이 그 접미인 것만 잇는다(`고양이+들[접미:들]+이[서술격:이]+다`, `사과+씩+이+다`, `마당+끼리+(이)[서술격:이(빠짐)]+다`). 수 단위 뒤의 후보(`afterUnits`)와 같은 틀이고, 빠진 이가 앞말에 묻는 체언 판정은 접미 앞의 줄기가 받는다. `쯤`과 이름 뒤의 접미 `이`(`영숙이이다`) 뒤에는 서술격을 읽지 않으며, `고양이들이`의 주격 후보는 그대로 선다.
- 두 조각이 합쳐진 글자(`addFused`, 표는 `fused_table.go`, 준말 목록은 `data/tables/contracts.tsv`). `셨`·`셔`·`십`은 줄기의 끝 음절 `시`에 조각이 합쳐진 것으로 읽는 자리마다 높임 선어말 `시`로도 읽는다(`honors`: `가+시+(었)+다`, `가+시+(어)서`, `가+시+(ㅂ)니다`). 높임 `시`는 모음 뒤에 서고, 받침(ㄹ 아닌) 뒤에서는 이음 `으`가 앞에 선다(`읽+으+시+(었)+다`, 그래프 `이음:으`). 이음 `으`는 조각 하나이고 `시` 앞과 맺음 니·니까·나·냐 앞, 줄기 뒤와 선어말 었·겠 뒤에 선다(`linked`: `읽+으+시+고`, `먹+었+으+니`; 예외 `Listed`에 `Not`). 으를 받는 다른 맺음은 표에 으가 든 꼴이 따로 있다(으면, 은, 을). 으가 든 꼴(은, 을, 음, 읍시다, 으면 …)은 ㄹ 아닌 받침 뒤에만 붙는다(`euAfter`): ㄹ 받침 줄기는 ㄴ·ㄹ·ㅁ과 으 없는 꼴을 받는다(`물 것`, `살면`). 문법 표는 "받침 뒤"로 적고 있어 이 층의 색인에서 좁힌다. 다만 낱말 표가 있으면 ㄹ을 빼지 않고 꾸밈 맺음 `은`·`을`을 붙인 꼴도 표의 용언 줄기 뒤에서 읽는다(`looseClosings`: `줄+은[꾸밈:은]`, `살+을[꾸밈:을]`. 한글 맞춤법 제18항에 어긋난 꼴이고 바른 꼴은 `준`, `살`). 따로 둔 색인 항목이고 ㄹ 받침 뒤에만 붙으며(`AfterLiquid`), 앞말이 표의 용언 줄기여야 하고(`앞말:용언`), 반박 "으가 든 꼴은 ㄹ 아닌 받침 뒤에 붙는다"(`PieceAfter`, 힘은 `forceClash`)가 낮춘다. 표의 꼴대로 읽은 풀이(`줄[의존명사]+은[보조사:은]`, `주+(ㄴ)`)는 그대로 선다. `으면`, `음` 같은 다른 으 꼴은 넓히지 않았다. 줄기 풀이(`마시+(었)+다`)는 그대로 나란히 서고, 낱말 표의 갈래 맞춤이 둘을 가른다. `잖`은 맺음 `지`와 `않`으로 풀고 뒤의 맺음은 `않`에 붙는다(`negated`: `하+(였)+지+(않)+아`). 맺음 `어야`(합쳐진 꼴 포함) 바로 뒤의 `겠`은 `어야 하겠`에서 `하`가 준 것으로 풀어 보조 용언 `하`를 괄호에 적고, `겠`과 뒤의 맺음은 `하`에 붙는다(`obliged`, `mustNames`: `가+(아)야+(하)+겠+다`, `먹+어야+(하)+겠+네`). 같은 단위 안에서 `어야` 뒤에 바로 붙은 `겠`만이다(띄어 쓴 `겠다`는 읽지 않는다). 표의 맺음 `죠`, `십시오`, `세요`, `더라`는 조각으로 풀어 찍는다(`splits`: `그렇+지+(요)`, `가+시+(ㅂ)시오`, `가+시+(어)+요`, `하+더+라`). 풀어 찍은 맺음은 조각을 하나씩 읽은 풀이와 같은 갈래라 한 번만 올라간다. 찍힌 이름 가운데 `맺음:ㅂ시오`와 `부정:않`은 그래프가 따로 없는 조각 이름이다. 앞말이 정해진 꼴(`contracts`: 이게, 이건, 이걸, 뭘, 무얼, 누가, 누굴, 누군, 여긴, 여길, 우린, 우릴, 그땐, 땐 들과, 대명사 꼴 내·네·제 뒤의 격조사 `게`인 내게·네게·제게(`내+게[부사격:에게]`), 어디·여기·거기·저기 바로 뒤의 `다`·`다가`인 어디다·여기다가 들(`어디+다[부사격:에다]`, `여기+다가[부사격:에다가]`). `게`와 `다`·`다가`는 글자 그대로 적고 표의 `에게`·`에다`·`에다가` 줄의 이름과 횟수로 읽는다. 낱말 표가 있으면 한 음절 대명사에 받침으로 붙은 조사 난·넌·전·날·널·절·걘·얜·쟨도: `shortPronouns`)은 낱말과 그 아래의 조사로 풀고(`fixed`: `이것+(이)[주격:이]`), 뒤에 조사가 더 붙는지는 그 조사의 갈래로 사슬 표가 정한다(`이것+(은)+요`). 닫힌 집합이라 표에 적힌 꼴만 읽고, 낱말 표가 그 낱말을 모르면 꼴의 이름(`줄임:이게`)으로 안다. 일반 낱말 뒤의 받침 조사(`친군`)는 읽지 않는다(갈래 수를 줄이려는 선택이다). 꾸밈 맺음으로 끝난 어절 바로 뒤의 `게`·`건`·`걸`은 의존명사 `거`와 그 아래의 조사다(`하+는 거+(이)`, `하+(ㄴ) 거+(는)`; 예외 `PieceIs`, 기준 `PieceAdn`에 `Not`. 꼬리를 찾는 자리에서는 "어느 후보든 꾸밈꼴이 여기서 끝난다"로 묻고, 후보에 이을 때 그 후보의 마지막 어절로 같은 그래프에 다시 묻는다: `again`). 겹치는 맺음(ㄹ게, ㄹ걸)과 낱말은 지우지 않고 나란히 선다. `거`를 `꺼`로 적은 `껀`·`껄`은 낱말 표가 있을 때 같은 자리에서 읽는다(아래 오표기 줄). 꾸밈 맺음으로 끝난 어절 바로 뒤의 `테`는 의존명사 `터`에 서술격 이다의 줄기가 합쳐진 것으로도 읽는다(`nounCopulas`, `addNouns`, `nounCopula`: `하+(ㄹ) 터+(이)+니까`, `가+(ㄹ) 터+(이)+(ㄴ)데`. `터이니`, `터인데`가 줄어든 꼴이다). 뒤에 이다가 받는 맺음이 바로 붙거나(`테니`, `테고`, `테야`) 받침으로 합쳐진다(`텐데`, `텐가`). 그래프 `줄임:테`의 예외는 셋이다: 앞 어절이 꾸밈 맺음으로 끝나지 않는다(`PieceIs`, 기준 `PieceAdn`에 `Not`. 게·건·걸과 같이 후보마다 다시 묻는다), 뒤의 맺음이 이다에 붙지 않는다(`Listed`), 뒤의 조각이 이 글자의 모음에 합쳐진 어/아나 ㅆ이다(`Listed`, 목록은 `fusedNames`: `터이+어`는 `테`가 아니다). 이는 글자에 흔적이 있어 `(이)[서술격:이]`로 찍고 흔적 없는 조각의 값을 치르지 않는다. 줄기 `터`는 낱말 표가 있으면 표의 체언으로, 없으면 꼴의 이름(`줄임:테`)으로 선다. 낱말 `테`로 읽은 풀이와 같은 글자의 낱말(`테고`, `테지`)은 그대로 나란히 선다.
- 낱말 속에도 흔한 합쳐진 글자(`addWide`, 표는 `wide_table.go`, 줄임 맺음·조사·선어말은 `data/tables/short-closings.tsv`, `short-particles.tsv`, `short-slots.tsv`)는 낱말 표가 있을 때만 읽고, 다른 풀이를 지우지 않고 나란히 세운다. 앞말이 낱말 표의 용언 줄기(줄어든 조사는 체언)여야 한다: 꼬리가 줄기를 만나는 자리에서 그래프 `앞말:용언`·`앞말:체언`이 판정한다(`gated`, 예외 `StemKind`). 높임 `시`가 든 `신`·`실`·`심`·`세`는 `셨`과 같은 자리(줄기 끝 `시`+조각으로 읽는 곳)에서 `시`를 한 칸 끼워 읽는다(`가+시+(ㄴ)다`, `가+시+(ㄹ)까`, `가+시+(ㅁ)+을`, `가+시+(어)+요`, 받침 뒤 `읽+으+시+…`). 글자의 그래프(`합침:신` 들)의 예외: 받침만 떼어 낸 꼴 바로 뒤에 조사가 붙는다(`PieceRight`, `사신이`. `심`은 예외), 떼어 낸 받침이 뒤 토큰과 표의 맺음을 이루지도 단위가 끝나지도 않는다(`PieceRight`, `사신고`). `세`는 `요` 앞에서만 읽는다. 인용이 줄어든 맺음(`대`, `ㄴ대`, `는대`, `래`, `으래`, `재`, `단`, `ㄴ단`, `는단`, `란`, `으란`, `잔`)과 `진`·`긴`·`길`은 한 조각이고 이름에 본디 꼴을 적는다(`간+대[맺음:ㄴ대(ㄴ다고 해)]`, `하+진[맺음:진(지는)]`). `달까`(다고 할까), `ㄴ달까`·`는달까`(ㄴ다고 할까, 는다고 할까), `랄까`(라고 할까)도 한 조각이다. `달까`는 형용사 줄기 뒤에 바로, 동사는 `ㄴ달까`·`는달까`로, `랄까`는 동사 뒤에 서고, 서술격 이다는 `랄까`를 받고 나머지 셋은 받지 않는다(`학생+이+랄까`). 바로 뒤에 조사가 붙으면 기각하고(`요`는 받는다), `대`·`단`은 형용사 줄기 뒤에 바로, 동사는 `ㄴ대`·`는대`로, `래`·`재`·`란`·`잔`은 동사 뒤에 선다(`kindTails`). 줄어든 조사 `선`(에서는)·`론`(로는)은 `엔`·`에선`처럼 한 조각이고 사슬을 닫는다(`여기+선[부사격:선(에서는)]`). 인용에 과거가 합쳐진 `댔`·`랬`·`쟀`(다고/라고/자고 했)은 선어말 자리의 한 조각이고(`shortSlots`: `가+(ㄴ)댔+어`, `하+랬+는데`), `냬`(냐고 해)는 맺음 한 조각이다. 사전에 없는 꼴이고 `해` → `했`과 같은 이치로 읽는다.
- 숫자(`addNumbers`, 표는 `number_table.go`). 숫자만으로 된 열은 수다(`수:숫자열`, `3[수]`). 글자가 섞인 열(`L2`, `v1`)은 영숫자 열로 남는다. 소문자 `0x` 뒤에 16진 숫자(0-9, a-f, A-F)가 하나 이상 이어진 열은 수 `수:16진법`이고 한 가지로만 읽으며(`hexRun`, `joinChain`: `0x1234[수:16진법]`, `0xFF`), 그 뒤의 조사·맺음·단위·큰 수·서술격은 숫자 열이 받는 것과 같다(`0x1234면` → `0x1234[수:16진법]+면[맺음:면]`). `0x`만 있는 열, `0x12G4`, `0X1F`는 영숫자 열이다. 숫자만으로 된 열 하나가 0과 1로만 이루어져 있으면(한 글자도) 수 후보에 더해 `수:2진법` 후보를 하나 더 낸다(`numberReads`: `1010[수]`, `1010[수:2진법]`. 성립과 선호가 같고 `[수]`가 먼저다. 단위·조사·맺음이 붙어도 두 후보가 다 선다: `10[수:2진법]+개[단위:개]`, `100[수:2진법]+%[단위:%]`). 기호로 이어진 수(`1,000`, `1.01`, `10:10`)와 부호·돈 기호가 붙은 수는 이름을 기호의 그래프가 정한 한 덩어리라 2진법 후보가 없다. 숫자가 하나라도 섞이면(`102`) 없다. 두 숫자 열 사이의 기호 하나(`,` `~` `-` `:` `/` `.`)는 풀이마다 그래프가 판정하고(예외 `PartsShape`: 같은 기호로 이어진 마디들의 수, 자리 수, 값의 범위, 첫 마디의 머리), 선 풀이가 있으면 열을 한 수로 잇고 그 이름을 단다. 자릿수 `,`는 첫 마디 1~3자리와 그 뒤 3자리씩(`1,000[수]`), 범위 `~`·`-`는 두 마디, 시각 `:`은 1~2자리(0~24):2자리(0~59)에 초까지, 비율 `:`은 두 마디, 날짜 `-`·`.`은 4자리-월(1~12)-일(1~31), 날짜 `/`는 월/일, 나눔 `/`는 두 마디, 전화 `-`는 0으로 시작하는 2~4자리-3~4자리-4자리, IP `.`은 0~255 네 마디다. 겹치는 풀이는 후보가 따로 나온다(`10:30[시각]`과 `10:30[비율]`, `11/10[날짜]`와 `11/10[나눔]`, `2026.11.10[버전]`과 `2026.11.10[날짜]`, `1.2.3.4[버전]`과 `1.2.3.4[IP]`). 후보마다 성립과 선호가 같다. 수의 맨 앞에 선 `-` `+` `$` `₩`는 왼쪽에 글자가 붙지 않았을 때 수에 든다(`-3[부호]`과 `-3[수]`, `$40[돈]`과 `$40[수]`; 단위 가장자리의 이 기호와 수 뒤의 `%`·`℃`는 떼지 않는다, `trimUnit`). 수 바로 뒤에는 `여`(어림), 단위 표의 낱말, `째`(차례)가 이 차례로 조각으로 선다(`units`, 예외 `PieceIs`, 기준 `PieceNum`에 `Not`): `3[수]+개[단위:개]+를`, `3+번+째`, `10+여`, `20+ms[단위:ms]`. 단위 표(`data/tables/units.tsv`)는 닫힌 표이고 수 뒤에서만 읽는다. 표의 줄은 글자와 이름이고, 조각 이름은 `단위:<이름>`이다(이름 기준은 `data/README.md`: 표준 한글 이름, 줄임말 없음, 같은 단위는 글자가 달라도 같은 이름, 한글 단위는 글자가 이름. 글자 하나에 줄이 둘이면 `unitRows`의 줄마다 `addAfter`가 한 번씩 불려 그래프가 둘 서고 후보가 따로 나온다: `5[수]+m[단위:미터]`, `5[수]+m[단위:분]`. 영문·기호 단위는 한글 이름이다: `12[수]+GB[단위:기가바이트]`). 단위 뒤, `째`가 서는 자리에 접미 `짜리`·`가량`·`당`이 선다(`백+원+짜리`, `3+명+당`). 긴 단위와 그것의 앞쪽 짧은 단위는 맞는 자리마다 함께 읽는다(`3+개월`, `3+개 월`). 그 뒤에 조사 사슬과 서술격 이다가 이어진다(`3+개+이+다`). 수와 단위의 그래프는 반박이 없어 성립 1이고, 수 뒤 조각의 선호는 표의 항목 수로 고르게 나눈 값이다(표에 횟수가 없다; 분모는 단위 표의 줄 수 + `afterOthers`이고 글자 수가 아니다. 한 글자에 줄이 둘이면 둘 다 센다). 숫자와 영문 단위가 붙은 열(`12GB`)은 수와 단위 두 열로 갈리는데(`splitUnits`), 가르기 전의 열 전체가 한 줄기인 후보도 `열:영숫자`로 읽는다(`12GB[열:영숫자]`. `scan.wide`에 갈린 열의 시작과 끝을 적어 두고 `atomStem`이 원자가 맞지 않을 때 돌려준다. 낱말 표가 아는 낱말이 먼저다). 단위 뒤의 `~`는 뒤에 수가 오면 앞 어절을 닫는 조각이다(`1+월+~[범위] 3+월`).
- 단위 앞의 수(`numerals`, 표는 `numeral_table.go`). 규칙은 단위에 있다(예외 `PieceIs`, 기준 `PieceNum`에 `Not`). 수로 치는 것은 숫자 열, 붙여 쓴 한글 수사, 표의 영문 글자다. 고유어 수사는 단위 앞 꼴 한·두·세·네·다섯·여섯·일곱·여덟·아홉(혼자, 또는 `열` 뒤: `열두`), 혼자 서는 열·스무·몇·여러다. 한자어 수사는 일~구와 십·백·천·만·억·조를 글자마다 읽되 일~구 둘이 맞닿지 않는 열이고(`삼십`, `이백`, `삼천오백육십칠`. 길이 한도는 없다), `수`는 맨 앞에서 큰 수 앞에만 선다(`수십`). 영문 글자는 `N` `n` `X` `x` `K` `k`가 그 글자 하나로 열일 때만이다(`N개`; `Nx개`, `L2개`는 아니다). 이런 수는 줄기로 `한[수]+개[단위:개]`처럼 찍히고, 선호는 표의 항목 수로 고르게 나눈 값이다. 숫자 열 뒤의 십·백·천·만·억·조는 조각 `큰 수:<꼴>`로 단위 앞에 선다(`7[수]+만[큰 수:만]+장`, `3+천+만+원`, `10+억`). 한글 수사나 영문 글자 뒤의 단위는 뒤에 글자가 그대로 이어지면 기각한다(예외 `PieceRight`): 조사 사슬, 서술격 이다, `째`가 오거나 거기서 단위(띄어쓰기 사이)가 끝나야 한다(`사회적`의 `회`는 단위가 아니다). 낱말 표가 있을 때 숫자 열 뒤의 단위는 글자가 이어져도 어절을 닫는다(`10+개 언어`). 한 음절 한글 수사와 단위를 합친 글자열이 낱말 표의 낱말이거나 줄임 꼴이면 반박 `PieceIs`(기준 `PieceWhole`)가 단위 풀이를 뒤로 보낸다(`이건`, `세대`, `조건`은 통짜 낱말이 먼저 선다). 낱말 표가 없으면 한자어 한 음절 수사(일~구)는 홀로 수 자리에 서지 못한다(예외 `PieceIs`, 기준 `PieceLone`). 고유어 수(한, 두, 세, 네, 몇 …)는 그대로 받는다. 띄어 쓴 `세 개`는 읽지 않는다.
- 조사 사슬은 "앞 조사의 갈래 → 뒤에 올 수 있는 조사의 갈래" 표(`rule.Links`)로 판정한다. 표준 문법의 일반 규칙이고, 표에 없는 짝은 기각한다(`결+과+가`, `마당+에+서`). 사슬의 길이 한도는 없다: 갈래 표가 허락하는 대로 읽는다(`친구+에게서+부터+는+요`). 조사의 풀이마다 갈래가 따로다(`linkOf`: `에서`의 주격 풀이는 격조사, 부사격 풀이는 부사격). 예외를 더하려면 그 조사 풀이의 그래프에 예외 간선을 얹는다(`markerGraph`). 모음 뒤의 강조 `야`(`에야`)는 이 층만 읽는 `보조사:야`다. 이 층만 읽는 조사는 `ownParticles`에 있다: `은커녕`·`는커녕`(통짜 조사), 부사격 조사 뒤에만 서는 강조의 `가`(`에서+가`, 갈래 `LinkEmph`). 앞 조사의 사슬로만 이어 읽으므로 수 단위 뒤(`3건가`), 높임 뒤, 맺음 뒤(`먹기가`, `먹는지가`)에는 서지 않는다. 줄기 바로 뒤에서 단위를 끝내는 보조사 `이야`·`야`(`leading`)는 그 뒤에서 마침표·물음표·느낌표가 단위를 닫으면 서지 못한다(예외 `PieceIs`, 기준 `PieceClosed`: `문제야.`는 `문제+(이)+야`). 앞말을 내세워 뒤의 서술로 잇는 조사라 문장이 대체로 그것으로 끝나지 않는다. 닫는 부호는 단위의 글자에서 읽는다(`unitScan`, `closes`: 읽는 글자 바로 뒤의 `.` `?` `!`. 이어진 점은 말을 줄인 것이라 닫지 않는다: `나야 뭐...`). 부호가 있는 단위의 끝에서만 그 조사들의 그래프에 그 사실을 넣어 다시 묻고(`onStem`, `groupAt`), 다른 조사 뒤나 맺음 뒤의 `야`는 묻지 않는다(`에서야.`, `하고 나서야.`). 부호 없이 끝난 문장의 마지막 단위는 단위 밖의 사실이라 보지 않는다. 호격 `야`는 앞말이 그래프 `앞말:부르는 말`을 지나야 선다(`calledGate`, 예외 `Listed`: 앞말이 닫힌 집합의 의존명사다. `거야.`는 `거`를 부르는 말이 아니다). 조사의 풀이마다 그래프가 따로여서 앞말 판정도 풀이마다 따로다: 문장 가운데의 `거야`는 `거+야[보조사:야]`로만 서고, 호격 풀이는 앞말 `거`가 부르는 말이 아니라서 서지 못한다. 앞말이 부르는 말이면 두 풀이가 나란히 선다(`철수+야[보조사:야]`, `철수+야[호격:야]`). 연결 어미 지·고·게·어 바로 뒤의 보조사 도·는·만·야는 같은 어절의 조각이다(`보+지+도`, 그래프 `사슬:맺음 뒤 보조사`). 그 짝이 표의 맺음이면(어도, 지만) 그 맺음으로만 읽는다. 묻거나 헤아리는 맺음 ㄴ지·는지·은지·ㄹ지·을지 바로 뒤의 조사도 같은 어절의 조각이다(`맞+는지+를`, `좋+은지+는`, `가+(ㄹ)지+도`, 그래프 `사슬:물음 맺음 뒤 조사`). 이 맺음으로 닫은 절은 체언처럼 쓰여 보조사 도·는·만·야와 격조사 가·를·에·와를 받는다(`askClosings`, `askParticles`). 예외는 둘이다: 앞의 맺음이 그 다섯이 아니다(`Listed`에 `Not`, 앞 조각의 이름), 조사가 그 여덟 꼴이 아니다(`Listed`에 `Not`, 조각의 꼴). 그 조사 뒤에는 사슬 표가 허락하는 조사가 더 이어진다(`하+(였)+는지+에+는`). 꾸밈 맺음과 `지`로 가른 풀이(`맞+는 지+를`)는 그대로 나란히 선다.
- 받침 없는 말 바로 뒤의 `에`+`요`(`고양이에요`)는 글자가 맺음 `예요`를 `에요`로 잘못 적은 꼴과 같다. 그래서 조사 풀이 `부사격:에`의 그래프에 반박을 하나 건다(`echoes`, `markerGraph`): 주장 "이 `에`는 부사격 조사다"를 `forceClash`로 낮춘다. 사실 `PieceYoOpen`(`rule.Piece.YoOpen`)이 참일 때 걸린다. `에` 바로 뒤가 보조사 `요`이고, 다음 둘 가운데 하나가 참이어야 한다(`yoOpen`): `에`가 줄기 바로 뒤에 서고(사슬의 첫 조각) 그 줄기의 마지막 글자가 받침 없는 한글 음절이다, 또는 `에`가 줄기 위의 접미 `이` 바로 뒤에 선다(글자로 읽는다: `에` 앞이 `이`이고 그 앞 글자에 받침이 있다. 접미 `이`는 받침 뒤 사슬의 맨 앞에만 서고, 접미 `이`로 끝난 말은 `이`로 끝나므로 받침 없는 말 뒤라는 뜻은 같다). 어느 것이 사슬의 첫 조각인지는 사슬을 오른쪽에서 왼쪽으로 읽는 동안에는 모르므로, 뒤에 `요`가 오는 자리의 조사는 줄기 바로 뒤의 후보로 한 번 더 묻는다(`onStem`, `groupAt`의 `onStem`). 후보는 지우지 않고 뒤로 갈 뿐이다(성립 2/(1+0.5)-1, 약 0.33). 낱말 표가 있든 없든 건다(없을 때는 줄기가 새 낱말이라 후보의 성립이 이미 1/3이어서 값이 달라 보이지 않는다). 받침 있는 말 뒤(`집에요`), 서술격 뒤(`학생이에요`의 `이`+`에요`), `아니에요`, 띄어 쓴 `에요` 단위, `에` 뒤가 `요`가 아닌 사슬(`학교에는`, `학교에서요`, `학교에`)에는 걸리지 않는다. `학생+이[접미:이]+에+요`도 이 반박을 받아 성립 0.33으로 내려가고 후보는 남는다. 다른 조사 뒤의 `에`(`에` 앞에 접미 `이` 아닌 조사가 있는 사슬)에는 걸지 않는다.
- 닫힌 집합 낱말(의존명사, 보조 용언, 관형사, 접속 부사)은 열쇠다. 낱말마다 그래프가 있고, 낱말 표가 없을 때 그 그래프가 판정한다: 그 집합이 뒤에 붙은 것을 받지 않으면 예외 `StemTail`이 꺾는다(보조 용언 줄기는 홀로 서지 못하고, 관형사 뒤에는 선어말·맺음이 붙지 않는다. 조사는 막지 않는다). 관형사 가운데 대명사이기도 한 `이`·`그`·`저`는 조사나 서술격 앞에 서면 이름을 대명사로 붙인다(`pronounName`: `그[대명사:그]+의`. 홀로 서면 `그[관형사:그]`). 표에 없는 토큰 열은 `새 낱말` 그래프가 판정한다(주장에 "열쇠 표에 없다"는 반박이 힘 0.5로 붙어 verdict 1/3). 표지가 붙은 새 낱말 줄기가 ㅆ 받침으로 끝나면 서지 못한다(예외 `StemCoda`, 낱말 표가 있을 때만 그래프에 건다). 단위 안의 경계 뒤에 선 통짜 새 낱말은 그 글자열이 그 자리에서 통째로 표지로 읽히면 서지 못한다(예외 `PieceIs`, 기준 `PieceMarked`: `선생님` 뒤의 `께서`). 글자열이 표지로 읽히는지는 `marked`가 읽고, 서는지는 새 낱말 그래프가 그 사실과 줄기의 꼴, 뒤에 붙은 것, 표가 아는 갈래를 한 번에 받아 판정한다(`unlisted`). 낱말 표가 있으면 그런 글자열은 꼬리가 붙은 새 낱말의 줄기로도 서지 못한다(`마당 에+서`, `것 이+다`). 이음 `으`로 시작해 표지 열로 이어지는 줄기도 그렇다(`으+며`, `으+로`, `으셨+다`). 표가 아는 낱말은 낱말로 선다. 낱말 표가 없으면 줄기에는 걸지 않는다(줄기 `들`과 접미 `들`을 가를 수 없다): 그때는 그 예외를 "뒤에 표지가 붙었다"(`StemTail`)가 다시 꺾게 그래프를 짠다.
- 색인(`index`)은 표지 꼴의 마지막 토큰에서 그 표지들로 간다. 합쳐진 토큰은 토큰 그대로와 받침(ㄴ, ㄹ, ㅁ, ㅂ, ㅆ)·모음(어/아)의 열쇠 양쪽으로 찾는다(`keysAt`). 받침·모음 판정, 붙는 조건, 사슬과 칸의 순서 같은 조건식은 `pkg/rule`의 것을 `nlgeul parse`와 함께 쓴다.

## 스트림 읽기

- 단위는 띄어쓰기 사이다. 단위 앞뒤의 기호는 읽는 글자에서 떼어 따로 올린다(아래 "가장자리 기호"). 문장을 단위로 가르는 단계(`unitsOf`, `cutter`)는 문장을 앞에서부터 훑으며 여닫는 기호에서도 가르고(아래 "여닫는 기호"), 글자 사이의 `+`에서도 가른다(아래 "기호와 영문·숫자 열"). 뒤를 보고 짝을 맞추지 않는다. 백틱 사이의 코드만 두 개씩 묶어 안의 띄어쓰기째 한 조각으로 두고 읽지 않는다(`` `a b`[코드]+를 ``). 단위를 읽을 때는 단위 밖을 보지 않는다.
- 토큰 자리마다 거기서 끝나는 표지 열을 색인에서 찾아 그래프를 돌린다(`tailsAt`: 조사 사슬 `chains`, 선어말 칸 `slots`, 맺음 `closings`). 기각된 것은 버린다.
- 후보(`path`)는 어절의 연쇄다. 어절은 줄기(새 낱말 또는 열쇠)와 그 뒤 표지들이다. 표지 없는 어절은 닫힌 집합 낱말이거나 단위의 끝에서만 선다.
- 성립은 조각 verdict의 최솟값, 선호는 조각마다 log10(관측 횟수 ÷ 표의 총 횟수)의 합이다. 횟수가 없는 표지와 줄기는 음절마다 log10(1/11172)로 친다. 표지의 횟수는 이 층만 읽는 표(`counts_table.go`, 값은 `data/tables/closing-counts.tsv`와 `particle-counts.tsv`)에 꼴마다 따로 있고(이형태 짝 이/가, 을/를, 면/으면도 저마다의 횟수. 다만 세요/으세요, 십시오/으십시오, 어다가의 세 꼴, ㄴ들/은들, ㅂ시다/읍시다, ㄹ뿐더러/을뿐더러, 이라고/라고, 아/야, 이시여/시여, 이든가/든가는 한 값을 함께 쓴다. 횟수의 출처와 확보일은 이 저장소에 기록이 없다), 합에는 같은 꼴을 풀이가 몇이든 한 번만 더한다. `nlgeul parse`가 읽는 문법 표의 횟수 칸은 그대로다. 합쳐진 어/아와 ㅆ은 풀어 쓴 꼴(아, 었)의 횟수로 친다. 후보의 수에는 한도가 없다: 그래프가 기각한 후보 말고는 모두 올린다(`top`은 후보를 나은 것부터 세우고 글줄이 같은 후보를 한 번만 둔다). 자리마다 남기는 후보를 줄이지 않고, 끝에 닿은 후보도 단위 전체를 앞 단위에 붙는 표지로 읽은 풀이와 합쳐 나은 것부터 모두 올린다. 어떤 후보도 다른 후보들 사이의 자리 때문에 빠지지 않는다.
- 줄기 끝 음절에 조각이 합쳐진 후보는 줄기를 본디 꼴로 되돌려 찍고(열쇠도 그 꼴로 찾는다), 합쳐져 있던 조각은 괄호에 본디 꼴로 적는다: `마시+(ㄴ)다`, `하+(ㅂ)니다`, `가+(았)+다`, `하+(여)서`, `쓰+(어)`(`restores`, `fusedTails`). ㅏ·ㅓ는 같은 모음의 줄기와 ㅡ가 빠진 줄기 두 갈래로 올린다(`써` → `써+(어)`, `쓰+(어)`). ㅡ가 빠진 줄기는 낱말 표가 르·러 불규칙으로 적은 줄기가 아니고 어/아가 ㅡ 앞 음절의 모음에 맞을 때만 선다(그래프 `줄기:되돌린 끝 음절`의 예외들, `restored`: `따르+(아)`, `치르+(어)`는 서고 `모라`를 `모르+(아)`로 읽지 않는다. 한 음절 줄기는 어뿐이다). 줄기 끝 `하` 뒤의 어/아는 여이고 `해`·`하여`로 글자에 드러나므로, 글자 그대로인 `하` 뒤에는 글자 없는 어/아를 읽지 않는다(`하지는`·`말하지는`을 `하+(아)+지+는`으로 읽지 않는다. 같은 그래프의 예외 "하 뒤의 어/아는 여이고 글자에 드러난다"(`Listed`, 닫힌 표 `yeoBases`)를 "합쳐진 조각이 글자에 흔적을 남겼다"(`PieceSame`에 `Not`. `restored`가 넣는다)가 다시 꺾으므로 `해`의 `하+(여)`는 서고, `가서`의 `가+(아)`도 그대로다). `놔`는 `놓+(아)`로도, 낱말 표가 있으면 `마`는 `말+(아)`로도 되돌린다(`하지 마`, `마라`). 줄기 끝 음절 `되` 뒤에서는 글자에 없는 어도 읽는다(`unspelt`, `unspeltAt`: `되+(어)도`, `되+(어)서`, `되+(어)야`, `되+(어)+요`, `되+(었)+다`). `돼도`, `돼서`, `됐다`로 적어야 하는 꼴(한글 맞춤법 제35항 붙임 2)을 `되도`, `되서`, `됬다`로 적은 것이고, 가·서·내·세처럼 겉으로 안 바뀌는 합침과 같은 자리에서 같은 값으로 읽는다(홀로 선 `(어)`는 흔적 없는 조각의 값을 치른다). `되+도[보조사:도]` 같은 다른 풀이는 그대로 선다. 영문·숫자 바로 뒤의 음절에서는 조각을 떼지 않는다(같은 그래프의 예외 `PieceAfter`. 하·되·이는 뗀다: `push하+(여)`, `latinBases`). 겉으로 안 바뀌는 모음 합침(가, 서, 내, 세)은 뒤에 조각이 더 있거나 단위의 끝이거나 바로 뒤가 보조 용언 줄기일 때만 읽는다(`가보다` → `가+(아) 보+다`). 보조 용언 줄기의 끝 음절에 조각이 합쳐진 글자여도 된다(`auxHead`: `빼줘` → `빼+(어) 주+(어)`, `가볼까`). 낱말 표가 있으면 합쳐진 어/아와 았/었은 흔적이 있든 없든 앞말이 표의 용언 줄기일 때만 선다(`asksStem`, 그래프 `앞말:용언`. 해·했은 묻지 않는다). ㅕ는 ㅣ+어(`마셔` = 마시)와, 낱말 표가 있으면 줄기 자신의 ㅕ+어(`켜` = 켜)로 푼다. `--cuts`의 자리는 원문 토큰 자리 그대로다.
- 맺음은 parse와 함께 쓰는 맺음 표에, 이 층만 읽는 표(`moreClosings`, 값은 `data/tables/closings-more.tsv`)를 더해 읽는다: 사전에 어미로 올라 있는 되, 어야지, 어야만, 어다가, 다면서·다며·다니 무리, 길래, 든가, ㄴ들, ㄹ망정, ㄹ지라도, ㄹ뿐더러, ㄹ세라, 으라고, 다만, 건만, 느냐고, ㄴ지라, 답니다 무리다. 낱말 표가 있으면 표의 용언 줄기 뒤에서 이름 꼴 맺음 기도 읽고(`gatedClosings`), 그 바로 뒤의 조사 사슬을 같은 어절의 조각으로 읽는다(그래프 `사슬:이름 꼴 뒤 조사`: `있+기+는`, `받+기+에+는`). 맺음 바로 뒤의 보조사(도·는·만·야)는 지·고·게·어/아와 어서·아서·면서 뒤에서 읽는다(`먹+어서+는`). 용언 줄기에만 붙는 맺음 은·는·을(꾸밈)과 아·어·나·여는 앞 글자가 한글 음절이 아니면(영숫자 열, 수, 코드, 경로, 파일명) 읽지 않는다(`push는`은 `push+는[보조사:는]`, `API을`은 `API+을[목적격:을]`). 그 맺음 그래프의 예외 "앞 글자가 한글 음절이 아니다"(`PieceAfter`, `hangulBound`)가 꺾는다: 영숫자 열로 된 용언은 `하`나 서술격 `이`를 사이에 둔다(`push하+는`, `API+이+(ㄴ)`). 이가 빠질 수 있는 다·고·면·지·네는 건드리지 않는다.
- 낱말 표가 있을 때 새 낱말 줄기가 서지 못하는 곳: 표지 꼴 줄기(`marked`. 받침을 뗀 `으`도 이음 으로 본다: `으+(ㄹ)걸`), 표나 닫힌 집합이 용언 아닌 갈래로만 아는 낱말이 서술어 꼬리 앞에 선 것(새 낱말 그래프의 예외 `StemKind`. "표에서 용언 줄기이기도 하다"와 "뒤가 서술어 꼬리가 아니다"가 그 예외를 꺾는다: `뭐+냐`, `거+네`). 경계 뒤의 통짜 새 낱말은 글자열이 표지 한 열이나 표지 두 열의 이음으로 읽히면 서지 못한다(`twoRuns`: `는게`).
- 낱말 표가 있을 때 새 낱말 줄기는 ㅆ 받침으로 끝나지 못한다(새 낱말 그래프의 예외 `StemCoda`): 표에 없는 줄기에 표지(조사, 선어말, 맺음)가 붙은 후보에서 줄기의 마지막 음절이 ㅆ 받침이면 서지 못한다(`떨어졌+다`, `떨+어 졌+다`). ㅆ 받침으로 끝나는 줄기는 `있`과 그것으로 된 낱말뿐이고(낱말 표에 있다) 나머지 ㅆ은 선어말 았·었·겠이다. 줄기는 조각이 합쳐지기 전의 꼴로 본다. 표지 없는 통짜 새 낱말(`떨어졌다`)과 표가 아는 줄기(`있+다`)는 그대로 선다.
- 낱말 표가 있을 때 꾸밈꼴 바로 뒤에 용언이 오지 못한다(`afterAdn`, 갈래 그래프 `열쇠:동사`·`열쇠:형용사`의 예외 `PieceIs`, 기준 `PieceAdn`): 한 단위 안에서 꾸밈 맺음으로 끝난 낱말 바로 다음 낱말이 낱말 표의 동사·형용사 줄기로 읽히면 그 후보는 서지 못한다(`떨+(ㄹ) 어지+(었)+다`). 의존 명사에 하다·싶다가 붙은 보조 용언의 줄기(`boundAux`: 듯하, 듯싶, 만하, 법하, 뻔하, 성싶, 성부르, 성하, 척하, 체하, 양하)는 그 예외를 다시 꺾는 예외 `Listed`로 선다(`아+는 척하+(였)+다`). 그 낱말 자신이 꾸밈꼴·이름꼴이면 예외 `PieceIs`(기준 `PieceTurned`, 사실은 `namesForm`이 읽는다)가 같은 예외를 꺾는다. 다음 낱말이 새 낱말, 체언, 관형사, 부사이면 걸리는 예외가 없다. 꾸밈꼴이 앞에 섰는지는 후보마다 다른 사실이라, 꾸밈꼴이 끝나는 자리에서 그 사실을 넣어 갈래 그래프에 다시 묻고 마지막 어절이 꾸밈꼴인 후보에만 그 답을 쓴다. 단위를 넘어선 이웃은 보지 않는다. 갈래 그래프가 줄기를 판정하는 둘째 겹부터다. 관형사 바로 뒤에도 용언이 오지 못한다(같은 두 그래프의 예외 `PieceIs`, 기준 `PieceDet`): 한 단위 안에서 표지 없이 선 낱말의 후보가 관형사이고(`determiner`: `이[관형사:이]`, `세[열쇠:관형사]`. 같은 낱말의 `열쇠:체언` 후보는 관형사가 아니다) 바로 다음 낱말이 낱말 표의 동사·형용사 줄기나 보조 용언 줄기로 읽히면 그 후보는 서지 못한다(`세 보+(아)`). 그 낱말 자신이 꾸밈꼴·이름꼴이면 선다(`어떤 마시+는`, 예외 `PieceTurned`). 의존 명사에 하다·싶다가 붙은 보조 용언은 꾸밈꼴 뒤에만 붙으므로 관형사 뒤에서는 꺾지 않는다. 홀로만 서는 낱말(감탄사 들, 그래프 `열쇠:홀로`)은 꾸밈 맺음으로 끝난 낱말 바로 뒤에도 관형사 바로 뒤에도 서지 못한다(`aloneExcept`, 예외 둘이고 꺾는 것이 없다. 표지 없는 낱말을 세우는 `whole`이 같은 `afterAdn`으로 묻는다). 체언을 꾸미는 말 뒤에는 체언이나 그 체언을 꾸미는 다른 말이 오고, 감탄사는 둘 다 아니다. 부사는 뒤의 관형사·꾸밈꼴을 꾸밀 수 있어 막지 않는다.
- 대명사 네·내·제는 이 층의 표(`pronounWords`)에 있고, 낱말 표가 있으면 체언 갈래로 친다(`네+가`).
- 단위 전체가 조사 사슬이나 서술격의 꼬리이면 앞 단위에 붙는 표지로 읽은 풀이를 하나 세운다(`attached`, `loneOf`: `+로[부사격:로]`, `+이[서술격:이]+(ㄴ)데[맺음:ㄴ데]`). 줄기 없는 어절이고 `Attach`가 참이다. 꾸밈 꼴 뒤에서 띄어 쓴 게·건·걸은 `거+(이)`로 읽는다. 띄어 쓴 `테니까`, `텐데`도 `터+(이)+니까`로 읽는다(단위의 머리가 그 글자이고 나머지가 그 뒤의 꼬리일 때). 줄기가 이 단위에 없으므로 성립은 새 낱말보다 높지 않고, 낱말이기도 한 글자(이, 가, 만)는 그 낱말 풀이와 경합한다.
- 남은 후보가 모두 합의한 자리에서 끊는다(`agreed`). 끊긴 구간마다 후보가 하나면 확정, 여럿이면 후보가 둘 이상인 경합이다(`bundles`). 찍을 때 확정은 한 줄, 후보가 둘 이상인 경합은 머리 줄과 갈래마다 한 줄이다(`render`; `--head`가 있으면 갈래 줄을 앞의 n개까지만 찍는다).

- 본용언의 어/아 꼴 바로 뒤에 붙여 쓴 보조 용언 줄기(닫힌 집합의 주·보·버리·놓·두·있, 낱말 표가 있으면 가·내·드리도)는 그 사이 경계의 값을 돌려받는다(`grow`). 그 줄기 뒤가 서술어 꼬리(선어말·맺음)일 때만이다: 같은 글자가 체언으로 서서 조사를 받으면(`주+는[보조사:는]`) 돌려받지 않는다. `지`(어지다)와 `하`(어하다)는 늘 붙여 쓰므로 경계를 세우지 않고 같은 어절의 조각으로 읽는다(`helped`: `지우+(어)+지+(ㄴ)다`, `예쁘+(어)+하+(ㄴ)다`). 낱말 표가 있고 본용언이 표의 용언 줄기일 때만이다.

`--trace`는 걸린 토큰 열, 그래프, verdict, 기각 이유를 찍고, `--cuts`는 측정용으로 후보마다 어절 끝 자리만 찍는다.

## 기호와 영문·숫자 열

낱말 표와 무관한 구조 규칙이다(낱말 표가 없어도 적용한다).

- 라틴 문자, 숫자, 밑줄이 이어진 열은 조각 하나다(`runsOf`). 그 안에서는 어절이 시작하거나 끝나지 않고, 그 안의 부분 문자열로 낱말을 찾지 않는다. 표에 없는 열은 `열:영숫자` 그래프가 판정한다(주장에 "열쇠 표에 없다"는 반박이 힘 0.25로 붙어 verdict 0.6, 자리 채움 값). 열 뒤에 한글 표지가 붙는다(`L2+의`).
- `.`은 풀이마다 그래프가 있다(`dotGraph`). 양쪽이 열인 점을 잇는 풀이 넷과, 앞 어절을 닫는 풀이 둘이다.

| 그래프 | 주장 | 예외 |
|---|---|---|
| `파일명:.` | 이름과 확장자를 잇는다 | 양쪽이 영숫자 열이 아니다, 오른쪽이 확장자 목록(`extensions`)에 없다 |
| `도메인:.` | 도메인의 마디를 잇는다 | 양쪽이 영숫자 열이 아니다, 맨 오른쪽 마디가 최상위 도메인 목록(`topDomains`)에 없다 |
| `소수점:.` | 수의 소수점이다 | 양쪽이 숫자가 아니다, 숫자 마디 둘이 아니다 |
| `버전:.` | 버전 번호의 마디를 잇는다 | 양쪽이 영숫자 열이 아니다, 마디가 모두 숫자(첫 마디는 v로 시작해도 됨)가 아니다. 점이 하나인 수는 소수점과 버전의 경합이다(`1.2[소수점]`과 `1.2[버전]`) |
| `마침표` | 문장이 끝났다 | 양쪽이 영숫자 열이다(`MarkBoth`), 점이 이어진다 |
| `줄임표` | 말을 줄였다 | 점이 하나뿐이다 |

- 잇는 풀이가 하나라도 서면 양쪽 열이 한 덩어리(`atom`)가 되고 줄기 뒤 대괄호에 선 풀이가 적힌다(`v1.2.3[버전]`). 둘 이상 서면 풀이마다 후보가 따로 나온다(`task.py[파일명]+에`와 `task.py[도메인]+에`). 후보마다 성립과 선호가 같다. 고를 근거가 없어 고르지 않는다.
- 닫는 풀이는 단위 안에서 앞 어절의 마지막 조각이 된다(`했+다[맺음:다]+.[마침표]`, `stopAt`). 단위 안의 쉼표 하나도 같은 길로 앞 어절을 닫는 조각으로 읽고, 쉼표를 낱말 속 글자로 둔 후보는 그대로 남는다(`가+,[쉼표] 나`와 `가,나`). 단위의 끝에 붙은 점은 가장자리 기호로 단위의 줄들 뒤에 한 줄로 찍는다(`.[마침표]`, `...[줄임표]`). 문장부호의 이름표에는 글자를 되풀이해 적지 않는다.
- 두 영숫자 열 사이의 빗금과 붙임표는 이름을 잇는다(`nameSigns`: `a/b[경로]`, `h-Cat[붙임]`). 양쪽이 숫자면 수의 기호다(`11/10[날짜]`과 `11/10[나눔]`, `10-20[범위]`과 `10-20[빼기]`). 아는 낱말 사이의 빗금과 붙임표는 그 낱말들을 한 줄기로 묶는다(`bound`: `입력/출력[대비:/]`, `원-달러[붙임:-]+를`). 낱말 표가 있고 마디가 모두 아는 낱말이거나 영숫자 열일 때만이다. 묶인 줄기의 선호는 마디마다 따로 쳐서 더한다(`partsPref`. 영숫자 열 마디는 토큰 하나다). 원자 하나인 줄기(`a/b[경로]`, `h-Cat[붙임]`)는 마디로 쪼개지 않고 토큰 하나로 친다.
- 문장의 낱말이 아닌 입력으로 시작하는 단위는 그 부분이 조각 하나다(`special`, `wholeAtom`): 주소(`http://`, `https://`), 전자우편, 경로(머리가 `/`·`~/`·`./`·`../`이거나 이름 사이 빗금이 둘 이상), 명령의 옵션(`-x`, `--xx`). 한글이 아닌 마지막 글자까지가 그 조각이고 안에서 낱말을 찾지 않는다. 뒤에 조사가 붙는다(`~/a/b[경로]+를`, `--xx[옵션]`).
- 단위 앞뒤의 기호 가운데 이름에 드는 것은 떼지 않는다(`trimmed`, `headKept`): 경로의 머리와 끝의 빗금, 옵션의 붙임표, 영문 앞의 `$` `_` `.`(`$HOME`, `.env`), 수 맨 앞의 부호와 돈 기호, 수 뒤의 `%`·`℃`. `@`와 `#`는 떼어 가장자리 기호로 읽는다.
- 한글과 영문·숫자 열이 맞닿은 자리는 표지가 없어도 어절이 끝날 수 있는 자리다(`change`): `toulmin엔진` → `toulmin` / `엔진`.
- 선호를 셀 때 한 덩어리는 토큰 하나로 친다(`tokens`).
- **단위 안의 기호를 제 어절로 읽는 길.** 글자 사이에 낀 가운뎃점(`apartSigns`: `·` `ㆍ` `・`)은 낱말 속 글자로 본 지금의 후보를 모두 두고, 그 기호를 조각 하나짜리 제 어절로 읽는 후보를 더한다(`prepare`가 `findMid`로 자리를 찾아 `scan.mid`에 둔다. 기호 그래프 `가운뎃점`이 판정하고 예외는 "같은 기호가 이어진다" 하나). 앞 낱말은 기호 앞에서 끝나고(`keptAt`: 그 자리에 남은 후보에, 기호가 경계를 보여 주므로 표지 없이 끝나는 낱말을 한 번 더해 `whole`의 `shown`으로 만든다. `best`에는 넣지 않는다) 뒤 글자는 새 낱말로 시작한다. 뒤에 표지가 붙지 않는다(`signWords`: 성립 1, 선호 0, 가장자리 기호와 같다. 단위 안 경계의 값은 뒤 낱말이 치른다). 읽는 동안 이 어절의 줄기 이름은 자리 채움 `기호`이고, 경합을 만든 뒤 `expandMid`가 어절의 끝 자리로 기호를 찾아 후보의 조각(`·[가운뎃점]`)으로 바꾼다. 단위 머리 바로 뒤의 자리는 찾지 않는다. `ㆍ`(U+318D)는 유니코드에서 글자라 `rule.Trim`이 떼지 않으므로 단위 가장자리는 `trimSigns`(문장부호·기호와 `signs.tsv`에 이름이 있는 글자)로 뗀다. 가운뎃점은 가르는 후보를 후보로 더할 뿐 이 층은 가운뎃점이 나열인지 셈인지 정하지 않는다.
- **`+`는 단위를 자른다.** 글자 사이(바로 앞과 바로 뒤에 글자가 있다)의 `+`는 자르는 단계(`cutter.cuts`, `cutSigns`)가 그래프 `더하기`·`연결`(예외: 같은 기호가 이어진다, 다른 기호와 맞닿아 있다 `MarkBySign`)를 돌려 후보가 서면 거기서 자르고 `+` 하나를 단위로 낸다(`곰+솔` → `곰`, `+`, `솔`). 가운뎃점과 달리 `+`를 낱말 속 글자로 본 후보는 남기지 않는다. 자르지 않는 것: `++`, `+=`, `C++`, 단위 맨 앞의 `+3`(수 앞의 부호), 코드 구간 안, 주소·경로·옵션 안(`special`이 아는 조각). `+`뿐인 단위는 `+[더하기]`와 `+[연결]`의 경합이다. 쉼표·가운뎃점·더하기의 쓰임은 정하지 않는다.

## 여닫는 기호

- 대상은 닫힌 표(`pairRows`, 값은 `data/tables/pairs.tsv`)의 기호다: `( )`, `{ }`, `[ ]`, `< >`, `" "`, `' '`, 둥근 따옴표 `“ ”` `‘ ’`, 낫표와 화살괄호 `「」『』《》〈〉`. 이름은 기호의 종류와 상관없이 `열기`와 `닫기` 둘이고 뒤에 깊이를 적는다: `([열기:1]`, `[[열기:2]`, `][닫기:2]`, `)[닫기:1]`. 깊이는 기호 종류를 가리지 않고 하나로 센다. 안쪽은 평소대로 읽는다(JSON인지, 코드인지 가리지 않는다).
- 확정하지 않는다. 자르는 단계는 "지금 기호가 열려 있을 수 있는 방식들"을 들고 문장을 앞에서부터 훑는다(`cutter.open`: 방식 하나는 열려 있는 여는 기호의 차례다. 처음에는 아무것도 열리지 않은 방식 하나). 기호를 만나면 방식마다 그 기호의 그래프를 돌려(`cutter.reads`, `cutter.judge`) 선 후보마다 방식을 하나씩 잇는다. 여는 기호는 그 방식에 열린 수보다 하나 깊게 열고, 닫는 기호는 같은 종류의 가장 가까운 여는 기호를 닫는다(깊이는 그 여는 기호의 깊이이고, 그 사이에 열리고 닫히지 않은 것은 함께 걷힌다). 깊이가 여럿 가능하면 후보를 따로 낸다: 한 후보에는 깊이가 하나다(`([열기:1]`과 `([열기:2]` 두 줄). 깊이만 다른 후보의 성립과 선호는 같다. 한도는 없다.
- 후보마다 그래프가 있다(`pairGraph`, 이름은 `열기:(`, `닫기:)` 꼴). 주장은 "이 기호는 묶음을 연다/닫는다"이고 예외는 이렇다.

| 후보 | 예외 |
|---|---|
| 닫기 | 같은 종류의 여는 기호가 열려 있지 않다(`MarkIs`, `MarkOpened`에 `Not`) |
| 여닫는 글자가 같은 따옴표(`"`, `'`)의 열기 | 같은 따옴표가 열려 있다(`MarkOpened`). 그래서 열려 있는 방식에서는 닫기로, 아닌 방식에서는 열기로 읽는다 |
| `'`, `’` | 낱말 가운데에 끼어 있다(`MarkBoth`, 양쪽이 영숫자 열: `it's`, `O'Brien`) |
| `<`, `>` | 앞뒤가 모두 빈칸이다(`MarkApart`: `x < y`), 붙임표나 등호와 맞닿아 있다(`MarkArrow`: `->`, `=>`, `<=`) |

- 어느 방식에서도 후보가 서지 않는 기호는 여닫는 기호가 아니다: 자르지 않고 전처럼 낱말 속 글자(가장자리에 있으면 가장자리 기호)로 둔다. 열려 있는 것이 없는 자리의 `)`가 그렇다.
- 헷갈리는 기호(`'`, `<`, `>`: 표의 `unsure`)는 열기·닫기 후보와 함께 글자로 본 후보(이름 없음)를 낸다: `'`는 `'[열기:1]`과 `'`의 경합이다. 그 방식은 열린 것이 그대로인 채로도 남는다. 헷갈리지 않는 기호도 후보가 서지 않는 방식이 섞여 있으면 글자로 본 후보가 함께 나온다.
- 여는 후보만 있는 기호는 홀로 한 단위다. 닫는 후보가 있는 기호는 뒤에 글자가 바로 붙어 있으면 그 글자까지 한 단위다(자르는 단계의 단위는 그대로다). **기호는 언제나 제 경합이다**: `readUnit`은 그런 단위(`readOnto`)를 기호 홀로의 경합(`spread`가 후보마다 갈래를 편 것: `)[닫기:1]`)과 붙은 글자의 경합으로 가른다. 붙은 글자의 경합은 머리 없는 평소 단위로 읽은 후보(통짜 새 낱말, 낱말 + 표지)에, 머리 달린 후보 가운데 기호를 첫 어절의 첫 조각으로 삼은 후보를 옮겨 합친 것이다(`moved`, `movedOne`): 첫 어절에서 머리 조각을 빼면 줄기 없는 어절이 되어(`Attach`) `+를[목적격:를]`로 찍히고, 성립은 그대로(1.00), 선호는 머리 기호 몫(머리만으로 선 어절의 선호)을 뺀 값이다. 모든 어절의 끝 자리에서 머리 길이를 뺀다. 기호를 낱말 속 글자로 삼킨 후보(`)를` 통짜)는 옮기지 않는다. 그 몫은 글자만으로 읽은 후보(`를` 통짜 새 낱말)가 맡는다. 코드 구간(백틱)의 머리는 이대로 한 경합이다(`` `a b`[코드]+를 ``). 뒤에 기호가 이어지면 닫는 기호는 홀로 한 단위다. 경합 사이에 빈칸이 있었는지는 `Bundle.Glued`가 알려 준다.
- **숫자 바로 뒤의 따옴표.** `"`와 `'`는 숫자 바로 뒤에도 여닫는 기호이고(`pairs.tsv`의 조건에서 "숫자 뒤 안 됨"을 뺐다) 단위 표(`units.tsv`)의 글자이기도 하다(`"`는 인치·초, `'`는 피트·분). 자르는 단계는 다른 여닫는 기호와 똑같이 자르되, 숫자 바로 뒤에 있고 단위 표의 글자인 기호는 단위에 그 사실을 싣고(`unit.measure`) 열려 있을 수 있는 방식에 이 기호를 만나기 전의 방식 전부를 더한다(단위로 읽으면 아무것도 열리거나 닫히지 않는다. `opened`). 그 기호의 경합에는 열기·닫기 갈래 뒤에 단위 표의 줄마다 갈래가 하나 더해진다(`measured`: `"[단위:인치]`, 줄기 아님, 성립 1, 선호는 단위의 선호). 그래서 `"6"`의 뒤 따옴표는 `"[닫기:1]`, `"[단위:인치]`, `"[단위:초]`의 경합이고, 따옴표 두 쌍이 든 문장에서 둘째 쌍의 열기·닫기도 선다. 영숫자 사이의 `'`(`5'10"`의 `'`)는 낱말 속 글자이고(`MarkBoth`) 낱말 표 없이도 `5[수]+'[단위:피트] 10[수]`가 선다(`units`: 바로 뒤 글자가 숫자이면 낱말 표가 없어도 단위 후보를 기각하지 않는다).

## 가장자리 기호

- 단위의 글자 앞뒤에 붙은 기호와 기호뿐인 단위는 같은 글자가 이어진 열마다 경합 하나로 올린다(`edgesOf`, `signBundles`). 이름이 붙는 기호는 닫힌 표(`signNames`)에 있고 후보마다 그래프가 있다(`signGraph`). 선 후보마다 갈래 하나이고 성립 1, 선호 0이다. 후보가 서지 않은 열과 표에 없는 기호는 이름 없이 글자만 올리고, 이웃한 그런 열은 한 경합으로 잇는다(`->`, `^^;`).

| 기호 | 후보 | 예외 |
|---|---|---|
| `,` | `쉼표` | 같은 기호가 이어진다 |
| `?` | `물음표` | 없음(몇 개든: `??[물음표]`) |
| `!` | `느낌표` | 없음 |
| `:` `;` | `쌍점`, `쌍반점` | 같은 기호가 이어진다, 어절 끝에 있지도 단위 전체이지도 않다 |
| `~` | `물결표` | 어절 끝에 있지도 단위 전체이지도 않다 |
| `#` | `제목` | 입력 줄의 맨 처음이 아니다, 바로 뒤가 빈칸이 아니다. 이름에 `#`의 개수를 붙여 찍는다(`##[제목2]`). 개수에 한도는 없다 |
| `#` `@` | `샵`, `골뱅이` | 같은 기호가 이어진다, 뒤에 글자가 바로 붙지도 단위 전체이지도 않다 |
| `#` `@` | `태그`, `명칭` | 같은 기호가 이어진다, 뒤에 글자가 바로 붙지 않았다 |
| `·` `ㆍ` `・` | `가운뎃점` | 같은 기호가 이어진다 |
| `+` | `더하기`, `연결` | 같은 기호가 이어진다, 다른 기호와 맞닿아 있다(`MarkBySign`) |
| `.` | `마침표`, `줄임표` | 위의 점 그래프 |

- `#`과 `@`는 후보를 둘 낸다: 기호 그 자체(`#[샵]`, `@[골뱅이]`)와 구실로 본 후보(`#[태그]`: 뒤의 말이 주제 표시다, `@[명칭]`: 가리키는 대상의 이름이다). 줄 맨 처음의 `# `는 `#[제목1]`과 `#[샵]`이다. 구실로 본 후보만 서면(`roleNames`: 줄 맨 처음의 `## `) 글자만 낸 후보를 곁에 둔다(`##[제목2]`와 `##`). 낱말 뒤에 붙은 `#`(`C#`)는 이름 없이 글자만 올린다. 쉼표의 쓰임(열거, 절 사이, 부름)은 정하지 않는다.
- 사실은 `rule.Mark`에 싣는다(`edgeFacts`): 열의 길이, 양옆의 글자, 단위 전체인가, 읽는 글자 뒤에 있는가, 읽는 글자가 바로 뒤에서 시작하는가, 입력 줄의 맨 처음인가, 바로 뒤가 빈칸인가, 다른 문장부호·기호가 바로 옆에 있는가(`MarkBySign`).

## 낱말 표

`Options.Words`(명령에서는 `--words` 또는 환경 변수 `NLGEUL_WORDS`)로 낱말 표를 주면 줄기를 그 표에서 찾는다. 표가 없으면 위에 적은 대로만 읽는다. 표의 형식은 탭으로 나눈 칸 다섯(검색 키, 갈래, 불규칙 유형, 횟수, 바른 꼴)이고 칸 넷뿐인 줄도 읽으며 `#`으로 시작하는 줄은 건너뛴다. 불규칙 유형은 ㄷ, ㅅ, ㅂ, ㅎ, 르, 러, 우를 읽는다. 낱말은 표의 줄이고 그래프가 아니다. 줄기를 표(`map`)에서 찾아 그 갈래·횟수·길이를 갈래별 그래프 여섯 개(`열쇠:체언`, `열쇠:동사`, `열쇠:형용사`, `열쇠:부사`, `열쇠:관형사`, `열쇠:홀로`)에 넘긴다(`stemVerdict`, 같은 사실은 한 번만 평가해 둔다. 기억의 열쇠는 그래프에 준 사실 전부다). 세 겹으로 쓴다(`--layers`로 겹을 줄여 잴 수 있다).

1. 여부: 표에 있는 줄기(풀어 쓴 꼴)는 아는 낱말이다. 없는 토큰 열은 그대로 새 낱말이다. 선호는 log10(횟수 ÷ 표의 총 횟수)다. 갈래가 둘인 키는 뒤를 받는 갈래의 횟수를 쓴다(`taken`: 명사 `작`은 형용사 `작`만큼 흔하지 않다).
2. 갈래 맞춤과 증거의 세기: 갈래별 그래프가 줄기를 판정한다. 주장 "이 줄기는 아는 낱말이다"를 예외 `rule.StemTail`(갈래가 뒤에 붙은 것을 받지 않는다)이 꺾고, 동사·형용사 그래프에서는 예외 `rule.PieceIs`(바로 앞 낱말이 꾸밈 맺음으로 끝난다, 바로 앞 낱말이 관형사다)도 꺾고, 홀로 그래프에서도 그 두 예외가 꺾고, 반박 `rule.SeenFew`(관측이 적다. 횟수 0인 줄도 한 번과 같이 친다)와 `rule.ShortKey`(한 음절이다)가 낮춘다. 닫힌 표의 구어 꼴(`spoken`: `것`을 구어로 이르는 `거`)에서는 예외 `rule.Listed`가 반박 "관측이 적다"를 꺾는다: 글말에서 센 횟수가 적다는 것은 구어 꼴에 불리한 증거가 아니다(`거[의존명사:거]`의 성립이 한 음절 반박만 받은 값이 된다. 선호는 그대로다). 줄기의 낱말이 단위 전체이면(줄기가 단위의 첫머리에서 시작하고 그 뒤가 그 줄기의 표지뿐이다) 예외 `rule.PieceIs`(기준 `PieceSole`)가 반박 "한 음절이다"를 꺾는다: 그 반박의 까닭은 한 음절 낱말이 긴 글자열 속에서 우연히 겹치기 쉽다는 것인데, 띄어쓰기가 낱말의 양 끝을 정해 준 자리에는 그 까닭이 없다(`하+자`, `가+는`의 줄기 성립이 1이 된다. 단위 안에 낱말이 둘 이상이면 전과 같다). 성립은 그래프가 낸 값 그대로다: 두 반박이 다 걸려도 새 낱말보다 조금 위다. 체언(명사, 대명사, 수사, 식별자)은 홀로 서거나 조사를 받고, 동사 줄기는 선어말과 모든 맺음을, 형용사 줄기는 동사 전용 맺음(`verbClosings`: 현재 ㄴ다/는다, 청유, 목적·의도)을 뺀 맺음을 받고 둘 다 홀로 서지 못하고, 부사는 홀로 서거나 보조사를 받고, 관형사와 그 밖은 홀로 선다. 닫힌 집합 낱말도 같은 판정을 받는다. 닫힌 집합 낱말의 이름(`관형사:이`)은 그 집합의 갈래로 섰을 때만 찍는다(`ownName`): 조사 앞의 `이`는 낱말 표의 체언으로 선 것이라 `이[열쇠:체언]+가`로 찍고, 두 집합에 든 `두`는 선 쪽의 이름만 찍는다(`두[보조 용언:두]+고`). 홀로 설 수 있는 아는 낱말은 단위 안에서도 표지 없이 어절이 된다.
3. 구조 값: 단위 안의 경계, 글자에 흔적이 없는 조각, 줄기에 값을 매긴다(`costBoundary`, `costUnseen`, `costPiece`). 색인의 표지(조사, 선어말, 맺음, 단위, 기호)는 조각 값을 치르지 않는다. 구조 값은 낱말 표가 없을 때도 매긴다.

불규칙 용언(`irr_table.go`, `changed`, `variants`). 낱말 표의 용언 줄기가 꼬리 앞에서 바뀐 꼴은 그 꼬리와 묶어서만 읽고, 본디 줄기로 찍는다. 바뀐 꼴은 홀로 줄기가 되지 않는다. 바뀐 꼴이 다른 낱말과 같으면 둘이 나란히 선다.

| 유형 | 바뀐 꼴 | 나오는 자리 | 예 |
|---|---|---|---|
| ㄹ 탈락 | 살 → 사 | ㄴ·ㅅ으로 시작하는 꼬리, 합쳐진 ㄴ·ㄹ·ㅂ 앞. 유형 표시와 무관하게 ㄹ 받침 줄기 전부 | `살+(ㄴ)다`, `알+는` |
| ㄷ | 듣 → 들 | 어/아, 으가 든 꼴 앞 | `듣+었+다`, `듣+으+니` |
| ㅅ | 짓 → 지 | 어/아, 으가 든 꼴 앞 | `짓+어`, `짓+은` |
| ㅂ | 돕 → 도우 (돕·곱은 도오도) | 으를 받는 꼬리의 모음 뒤 꼴, 합쳐진 어/아 앞 | `덥+(어)서`, `돕+(아)` |
| ㅎ | 파랗 → 파라, 파래 | 으를 받는 꼬리와 네 앞 / 합쳐진 어 | `파랗+(ㄴ)`, `그렇+(어)` |
| 르 | 모르 → 몰르 | 합쳐진 어/아 | `모르+(아)` |
| 러, 우 | 이르 → 이르르, 푸 → 프 | 합쳐진 어 | `이르+(어)`, `푸+(어)` |

오표기 줄(다섯째 칸이 있는 줄, 예 `맞기\t동사\t규칙\t0\t맡기`). 키는 틀린 표기이고 바른 꼴은 표의 다른 줄이다. 이 줄은 낱말(`lex`)에도 횟수의 합에도 들지 않고 적힌 꼴로 따로 둔다(`typos`): 들이면 `맞기`를 새 낱말로 읽는 후보가 아는 낱말 후보로 바뀌어 사라진다. 오표기 후보는 더해지기만 한다. 꼬리 앞의 글자(합쳐진 조각은 되돌린 끝 음절)가 적힌 꼴이고, 꼬리를 하나 더 낸다(`typoReads`, 차례는 본디 → 불규칙 → 오표기): 줄기는 바른 꼴(`맡기`)로 찾고 갈래 맞춤·되돌림·선호가 바른 꼴로 돈다. 바른 꼴이 오표기 줄의 갈래로 그 꼬리 앞에 서야 읽는다(`misspelt`: 갈래별 그래프가 줄기를 판정하되 `PieceMisspelt` 사실을 건다). 갈래 그래프 여섯 개 모두에서 반박 `rule.PieceIs`(기준 `PieceMisspelt`)가 주장을 `forceTypo`(0.28)로 낮추고 이를 꺾는 예외는 없다. 바르게 쓴 낱말보다 낮게 선다(그 반박만 걸리면 성립 2/(1+0.28)-1, 약 0.56. 바른 낱말의 성립이 0.98인 자리의 `맡기`는 0.55로 찍힌다). 찍을 때 줄기 이름 끝에 `,오타정정:<적힌 꼴>`이 덧붙는다(`corrected`, 기호와 이름은 `consts.go`의 상수 둘): `맡기[열쇠:동사,오타정정:맞기]+(어)[맺음:어(합침)]`. 읽는 자리: 표지 앞의 줄기, 표지 없이 선 낱말(`wholeTypos`: 단위의 끝이 아니어도 아는 낱말처럼 선다. 홀로 선 명사 `역활`, 붙여 쓴 `역활분담`, 하다 앞의 `설겆이하고`), 빗금·붙임표로 묶인 마디(`입력/역활을`: 묶인 마디 가운데 아는 낱말도 영숫자 열도 아닌 것이 오표기 줄에 있으면 바른 꼴로 읽고 첫 바른 꼴만 읽는다. 줄기는 마디를 바른 꼴로 바꿔 기호로 이은 `입력/역할`, 적힌 꼴은 `입력/역활`. 글자 그대로의 후보 옆에 더하는 후보이고 `boundTails`가 꼬리에 `boundTypo`를 달아 낸다). 읽지 않는 자리: 불규칙 줄기의 바뀐 꼴. 동사 줄기는 홀로 서지도 조사를 받지도 않으므로 `맞기`, `맞기가`에는 이 후보가 없다. 표지 없이 선 낱말도 바른 꼴이 표지 없이 설 수 있는 갈래(체언, 부사, 관형사, 홀로)일 때만 선다. 글자 그대로의 낱말 후보는 그대로 남는다. 본디 후보(새 낱말, `맞[열쇠:동사]+기[이름:기]` 들)는 그대로 선다.

닫힌 표의 틀린 표기 낱말(`typoKeys`)은 닫힌 집합 낱말 `거`를 된소리로 적은 `꺼` 하나뿐이고, 닫힌 표이므로 이 줄이 전부다(다른 목록·사전에서 옮긴 것이 아니다). 낱말 표가 있을 때 색인을 지으며 오표기 줄과 같이 든다(`addTypoKeys`: 갈래는 그 낱말이 닫힌 집합으로서 갖는 의존명사이고, 낱말 표에 같은 줄이 있어도 같은 바른 꼴이라 하나로 합쳐진다). 바른 꼴이 닫힌 집합 낱말이면 `misspelt`가 판정할 갈래를 낱말 표의 갈래와 닫힌 집합의 갈래에서 고르고(낱말 표에 `거` 줄이 없어도 선다), 이름은 `known`처럼 닫힌 집합의 이름을 준다(`ownName`): `거[의존명사:거,오타정정:꺼]`. 반박은 다른 오표기와 같다. 받침이나 맺음이 줄기에 합쳐진 `껀데`·`껍니다`도 되돌린 줄기 `꺼`로 읽는다. 꾸밈 맺음 바로 뒤의 `껀`(거+는)과 `껄`(거+를)은 `건`·`걸`과 같은 길로 읽는다(`typoContracts`, 낱말 표가 있을 때만. 줄기가 틀린 표기 `꺼`로 적혔음을 `contract`의 칸 `wrote`에 싣고, `fixed`가 그 꼬리에 `wrote`와 닫힌 집합의 갈래를 달아 `stemOf`가 `misspelt`로 판정한다: `거[의존명사:거,오타정정:꺼]+(를)[목적격:를]`. 띄어 쓴 꼴도 `attached`가 읽는다. `께`(거+이)는 읽지 않는다).

ㄷ·ㅅ 뒤의 으가 든 꼴은 본디 줄기의 끝 음절로 판정한다(`irrTails`, `linked`: `지은`의 은은 `짓` 뒤라 선다). 표가 규칙이라 적은 그러·이러·저러·어쩌의 그래 꼴은 닫힌 표(`eoStems`)로 읽는다. 받침 하나뿐인 맺음(ㄴ, ㄹ, ㅁ)은 낱말 표가 있으면 앞말이 표의 용언 줄기일 때 어느 음절 밑에서든 읽고(`예쁘+(ㄴ)`), ㄹ 받침 줄기의 ㅁ은 ㄻ에서 뗀다(`살+(ㅁ)`). 체언 + 이 빠짐으로는 열지 않는다.

맺음 오표기. 닫힌 표(`typoClosings`, `data/tables/typo-closings.tsv`의 17줄)에 든 틀린 표기의 맺음은 바른 맺음으로 찍고 이름 끝에 적힌 꼴을 덧붙인다. 표는 떠올려 적은 흔한 오표기이고 다른 목록·사전에서 옮긴 것이 아니다. 받침 ㄹ 밑에 쓴 꼴: `께`(ㄹ게), `껄`(ㄹ걸), `찌`(ㄹ지), `쑤록`(ㄹ수록), `려고`·`려면`(받침 ㄹ이 든 `갈려고`, `할려면`. 줄기는 `가`, `하`). 통음절 꼴: `을께`(을게), `을껄`(을걸), `을찌`(을지), `을쑤록`(을수록), `을려고`(으려고), `을려면`(으려면), `읍니다`(습니다), `슴`(이름 음), `구만`(구먼), `예요`(에요), `에요`(예요). 바른 맺음의 항목을 이름으로 찾아 복사해 만든 항목이 색인에 들고(`addTypoClosings`, `typoClosingEntry`), 이름·갈래·횟수·앞말 조건·`head`는 바른 맺음의 것 그대로라 이름으로 묻는 목록과 예외가 바른 맺음과 똑같이 걸린다. 다른 것은 꼴·받침(적힌 꼴의 것), 붙는 앞말(받침 밑 꼴은 어디든, 통음절 꼴은 바른 맺음의 것), 새 칸 `wrote`(적힌 꼴, `ㄹ께`)와 `right`(찍는 꼴, `(ㄹ)게`)다. 그래프는 적힌 꼴로 찍고(`markerGraph`) 반박 `rule.PieceIs`(기준 `PieceMisspelt`)가 `forceTypo`로 낮춘다(바른 꼴의 성립이 1인 자리에서 2/(1+0.28)-1, 약 0.56). 횟수의 합과 닫힌 맺음의 집합에는 들지 않는다. 오표기 항목은 같은 글자의 바른 항목과 한 조각으로 합쳐지지 않고(`entryGroup`), 그 글자가 새 낱말로 읽히는 후보(`구만`, `슴`)는 그대로 선다(`markedFrom`). 바른 맺음이 설 수 없는 앞말에는 서지 않는다(`책께`는 받침 ㄹ이 없다). 모르는 줄기 뒤에서 바른 꼴과 같은 방식으로 서는 것은 같다(`예쁠려고`의 `예쁘+려고`는 `예쁘려고`와 같이 이름 없는 줄기). 표에 없는 틀린 맺음은 읽지 않는다. 찍을 때 표지 이름 끝에 덧붙는 것도 `corrected`다(`게[맺음:ㄹ게,오타정정:ㄹ께]`).

반박의 힘, 문턱, 구조 값(`forceNew`, `seenEnough`, `forceFew`, `forceShort`, `forceWhole`, `forceClash`, `forceTypo`, `forceDropAdn`, `cost…`)은 자리 채움 값이다. 몇 가지 값을 문장 묶음에 재어 고른 것도 있으나 조각의 정답이 있는 자료로 맞춘 값은 아니다. 낱말 표가 있으면 후보의 차례는 선호 + log10(성립)이다(`before`). 성립이 낮은 후보도 남고 뒤로 갈 뿐이다.

그래프는 낱말 표 없이 521개(간선 1056), 낱말 표가 있으면 572개(간선 1201)다.

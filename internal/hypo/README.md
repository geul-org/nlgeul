# hypo

`nlgeul hypo`의 가설 나열(실험). 토큰 층이 올린 구조(`token.Reader.Bundles`)를 받아, 묶음마다 읽기를 하나씩 골라 이은 조합(가설)을 세고 정렬한다. 글줄을 다시 읽지 않는다.

| 이름 | 하는 일 |
|---|---|
| `Choices` | 가설이 읽기를 고르는 묶음들: `nlgeul token`이 찍는 묶음 그대로(재워 둔 읽기의 묶음은 뺀다) |
| `Count` | 가설 수(묶음마다의 읽기 수의 곱). 크기에 한도가 없는 수로 낸다 |
| `Picked` | 번호가 가리키는 가설의 읽기들. 번호 0은 모든 묶음의 첫 읽기다 |
| `List` | 모든 가설에 점수를 매겨 정렬한다 |
| `Line` | 가설 한 줄: 순위, 성립과 선호, 묶음별 읽기(` | `로 가른다). 읽기는 `token.Branch.String`이 찍는다 |
| `Limit` | 나열하는 가설 수의 상한(1000000). 메모리를 지키려는 안전장치이고 상수 하나다 |

## 정렬 공식

정렬 기준은 `order.go`의 함수 `order` 하나에 모여 있다. 그 함수만 고치면 정렬이 바뀐다.

- `score`: 고른 읽기들에서 가설의 점수(`Score`)를 낸다. 성립은 읽기들의 성립 가운데 최솟값, 선호는 읽기들의 선호의 합이다.
- `before`: 두 점수 가운데 어느 것이 먼저인가. 성립이 큰 것이 먼저, 성립이 같으면 선호가 큰 것이 먼저다.

점수가 같은 가설은 번호 순서(앞 묶음부터, 토큰 층이 낸 읽기 순서)로 남는다(`List`의 안정 정렬). 읽기가 하나뿐인 묶음도 다른 묶음처럼 토큰 층이 그 읽기에 준 성립과 선호로 들어간다. 기호뿐인 단위와 닫는 점은 성립 1, 선호 0이라 가설의 점수를 바꾸지 않는다.

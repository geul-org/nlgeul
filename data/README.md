# data

`nlgeul`이 읽는 자료 표를 두는 폴더다.

## words.tsv

토큰(음절) 스트림에서 낱말을 찾을 때 쓰는 검색 키 표다. 이 파일은 저장소에 들어 있지 않다(`.gitignore`로 제외). 따로 만들어 이 폴더에 넣는다.

형식: UTF-8, 줄바꿈 `\n`, 한 줄에 풀이 하나, 칸 다섯을 탭으로 나눈다(칸 넷뿐인 줄도 읽힌다). 맨 위의 `# `으로 시작하는 줄은 주석이다.

| 칸 | 뜻 |
|---|---|
| 1 검색 키 | 체언·부사 등은 낱말 그대로(`고양이`). 용언은 기본형에서 끝의 `다`를 뗀 줄기(`마시다` → `마시`, `작다` → `작`). 유니코드 NFC |
| 2 갈래 | 품사 이름(명사, 대명사, 수사, 동사, 형용사, 관형사, 부사, 감탄사, 식별자 등) |
| 3 불규칙 유형 | 용언의 활용 유형(`규칙`, `여`, `ㄷ`, `ㅂ`, `르` 등). 용언이 아니면 빈 칸 |
| 4 횟수 | 관측한 횟수 |
| 5 바른 꼴 | 오표기 줄에만 적는다. 그 줄의 키는 틀린 표기이고 갈래·불규칙 유형은 바른 낱말의 것, 횟수는 0이다(예 `맞기\t동사\t규칙\t0\t맡기`). 다른 줄은 비어 있다 |

- 한 키에 갈래가 여럿이면 갈래마다 한 줄이다.
- 불규칙 용언도 본디 줄기와 유형만 적는다. 바뀐 줄기는 표에 없다.
- 조사, 어미, 접사 같은 문법 조각은 이 표에 없다.
- 정렬: 키의 코드포인트 순, 같으면 갈래, 불규칙 유형 순.
